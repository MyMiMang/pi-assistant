# 0017 群聊去掉每轮 token 预算，自主推进好找、真能自己推进
- 日期：2026-10-20
- 状态：有效
- 决定：
  - 群聊每轮的 token 预算上限整个去掉（用户定：「不要这个预算上限」）。每轮发言次数 / 每人次数 / 派活深度这几道防空转的上限保留。
  - 「本轮已暂停」不再挡住叫醒管理者：任务提交、卡住、定时检查照常叫醒；暂停时存下的发言队列仍等用户点继续。
  - 自主推进开关放到群聊顶部，一处入口；用户交代需要多步、多人长期协作的事时，管理者主动发「目标 + 完成标准」确认卡，用户确认才开。
  - 开着自主推进时，目标没达成、手上没活，管理者在同一轮里规划下一步并派出去，不只汇报一句；管理者一轮结束后若目标未完成又没有进行中的任务，系统兜底再叫它一次（连续两次没有新进展就停，提示用户看一下）；目标达成由管理者明确结束自主推进并汇报。
  - 派活带附件（room_assign 的 files）要真的把文件放进负责人的工作区；找不到的附件不派出、写明原因，不再假装交接成功。
- 原因：2026-10-20 只读查看用户真实数据：每轮 40 万 token 预算把缓存命中的 token 也算进去，单次调用就读约 23 万，一晚暂停 9 次，每次都卡在成员交活、管理者该接着安排的时候；暂停期间唤醒被挡；自主推进开关藏在看板折叠行里，那个群从没开过；附件交接只拼了文件名。
- 不做什么：不按花费设预算（用户不要）；不去掉发言次数类上限；不在用户不知情时自动开自主推进。
- 影响：packages/server/src/rooms/（logic.ts、scheduler.ts、collab.ts、tools.ts、index.ts）、apps/web/src/components/（RoomChat.tsx、WorkItems.tsx、Attachments.tsx）、themes 样式；e2e group-collab-ui 等。

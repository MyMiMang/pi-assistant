# 0028 给助理设权限档位就开启「操作这台电脑」
- 日期：2026-11-05
- 状态：有效
- 决定：在助理档位（助理详情 › 电脑、输入栏「权限」按钮）里选一个档位并确认风险，就同时开启「操作这台电脑」并把这个助理加进允许名单；不用再去设置页审阅清单、勾同意、点「确认开启」。「限定」档还没选应用的助理不再挡住开启，只是暂时不能操作。
- 原因：用户给测速助理设了完全权限、也确认过风险，结果还是「未开启」，设置页按钮又因为别的测试助理是「限定」没选应用而变灰，用户说「搞这么复杂用户一下子就弃坑了」。
- 不做什么：不取消风险确认（调高档位照旧弹确认框，完全权限照旧是红色「确定启用」）；不把「限定、没选应用」悄悄当成「只看」（那会让它看到所有应用，是放大权限）。
- 影响：`packages/server/src/host-control.ts`、`routes/host-control.ts`、`apps/web/src/components/HostControl.tsx`；设计见 [host-enable-simple.md](../design/host-enable-simple.md)

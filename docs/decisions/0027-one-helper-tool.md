# 0027 后台任务并进帮手：只留一个派活工具
- 日期：2026-11-04
- 状态：有效（补充 0014）
- 决定：
  - 去掉给模型的 `spawn_task`（后台任务）工具，派活只用 `spawn_subagent`（帮手）。
  - 帮手结束或失败时一律叫醒派它的会话接着推进，结果核验后再汇报。
  - 主会话每派一个帮手，聊天里显示一张帮手卡片：在做什么、状态、查看过程、取消 / 继续。
  - 定时任务、主动巡检仍是「到点开一个帮手」，不变。
- 原因：两者底层本来就是同一套帮手，区别只在后台任务做完不叫醒助理，活停在半路；卡片也看不到过程，像盲盒。用户 2026-11-04 指出本质没有区别，要求合并、主动推进。
- 不做什么：不保留两个工具让模型选；不另写一套执行过程页（复用帮手执行页）。
- 影响：packages/ext-delivery、agent-runtime/background-tasks.ts、system-rules.ts、mock-provider.ts、Cards.tsx / ChatMessages、相关测试和 e2e。

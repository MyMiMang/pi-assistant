# 0025 助理默认自动、敢做事
- 日期：2026-11-03
- 状态：有效
- 决定：「主动做事」默认自动（新建和已有助理都是，主动等级已关的不动）：交代过的、在授权内的、看得出能帮上的事直接做完再告诉结果；对上用户写的「可以放心做的事」规则也直接做；巡检要看得见群并能在群里推进。试运行只是可选模式。对外承诺、花钱、破坏性、权限变更仍先问。
- 原因：用户的目标就是助理主动做事，现在基本不主动（巡检看不到群、提示词太保守、巡检常卡住）。
- 不做什么：默认试运行（会更不主动，用户否掉）；多人白名单、规则版本化。
- 影响：proactive.ts、ext-proactive、rooms、主动设置界面；设计 docs/design/proactive-observe-mode.md

# 0021 开发实测环境：用真实模型渠道测开发中的代码
- 日期：2026-10-23
- 状态：有效
- 决定：新增 `npm run dev:live`，用真实模型渠道跑开发中的代码做实测，不用每次打包再到装好的 App 里测。数据目录固定 `~/.pi-assistant-dev`、端口 8788，和装好的 App 完全分开；主密钥放数据目录里的文件（`PIA_SECRETS=file`），不碰系统钥匙串；模型渠道由用户自己在里面登录 / 填一次。实测只用新建的测试助理和测试群。
- 原因：用户 2026-10-23 要求「测试的时候走真实的，不然又要打包之后再测太麻烦」；同一天在 App 里拿用户自己的助理做测试，用户明确反对（会污染助理的记忆和对话）。
- 不做什么：不从装好的 App 里复制密钥或登录凭据；自动化测试（单测、e2e、`npm run check`）仍只用 Mock，不花钱；不在用户的 App 里用用户的助理 / 群 / 对话测试。
- 影响：`scripts/dev-live.mjs`、`package.json` 的 `dev:live`、`secrets.ts`（`PIA_SECRETS=file`）、AGENTS.md 硬规则 4。

# 0032 编程工具渠道的上下文由工具自己管，Pi 只补发增量
- 日期：2026-11-17
- 状态：有效
- 决定：用反重力 / Claude Code / Codex 等编程工具时，Pi 不按阈值自动整理；每轮只发工具没看过的内容（切换回来时增量补发期间的对话或摘要）；记忆块不进系统提示，改附在本轮消息前；上下文大小用真实值。
- 原因：原设计「整理上下文照旧由 Pi 负责」+ 记忆进系统提示，导致每条消息重开工具对话、重发全文，Pi 反复整理，额度耗得快（苏折竹一天整理 58 次）。
- 不做什么：每次切换都新开对话重发历史（用户选了增量补发）；改 Pi / agy 本体。
- 影响：docs/design/cli-context-ownership.md、docs/design/cli-models.md 第 44、90 行的说法、pi-adapter/cli-models/*

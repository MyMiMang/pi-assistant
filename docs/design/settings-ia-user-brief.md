# 设置重排：给用户看的产品方案（一页）

> 你说的问题我们复现并定位到了：**设置里 15 个标签平铺、没有分组**；本地运行时（Laya、SenseVoice）被塞进「模型服务」顶部；语音「用哪个模型」根本没地方选，程序自己挑（本地优先、否则第一个云，会静默计费）；子代理的「并发/最长运行」是**全局**值却放在「模型」页，看起来像每助理设置。下面是怎么改。

## 一、导航：15 个平铺 → 5 组 / 16 项

```
模型与语音             助理能力               偏好与系统
  模型服务               记忆                   外观
  语音配置 ✦新            技能库                 桌宠
                        扩展（MCP）            用量
电脑                                          下载与组件
  助理电脑               连接                    关于与更新
  操作这台电脑           渠道
                        邮箱
                        远程访问与设备
                        固定地址 / 入口
```

- 只加分组的**组标题**，还是一层点击，不变二级树；桌面显标题，手机上保持横向滑动。
- 所有原来的入口都还在，原来的网址（`?settings=host` 等）继续能用（`?settings=model` 也指向模型服务）。
- 「搬家」的只有：语音相关 → 语音配置；Laya → 操作这台电脑；子代理任务参数 → 每个助理的设置里（不新增入口）。

## 二、三块关键界面

### 1) 模型服务（瘦身后：只管「地址 + Key + 能力」）

```
默认使用（新助理）        [ 模型 · 思考强度 ▾ ]  [测试连接]

⌄ 模型服务   [7 个服务 · 2 个已配置]
  [搜索…]                          [+ 添加服务]
  [图标] OpenAI    [图标] 我的中转
  ▾ OpenAI
     gpt-4o            对话 · 识图     [能力]

     语音识别（ASR）声明：已声明 whisper-1
       → 真正用哪个，在「语音配置」里选
```
此页**不再有**本地 Laya、本地 SenseVoice、子代理。

### 2) 语音配置（新页：云 / 本地，你说了算）

```

云端：使用哪个模型 [ OpenAI · whisper-1 ▾ ]
      （没有可选时）⚠ 还没有可用的云端语音模型 → [去模型服务声明 ASR]
      说明：音频会先到本机服务，再转发给该服务（会离开本机）

      状态：未安装 / 已安装未运行 / 运行中（空闲 90s 释放）
      许可：模型权重许可未解决 —— 下载不可用
      [安装/导入权重] [启动] [停止] [卸载]   进度 ███░ 42%
      高级（折叠）：来源 / 系统路径 / 安装日志 / 空闲秒数

没有选择 = 未配置：麦克风会提示你去语音配置，不会自动改用云端（不静默花钱）。
```

### 3) 电脑 › 操作这台电脑 › 本地快速模型（Laya）

```
⌄ 本地快速模型（Laya）   [未安装]
   在有限候选里挑控件的快速分类模型（不是语音识别）
   这台电脑和助理电脑共用同一份安装；两边的「用不用、用哪个」分别设置
   [一键安装]  进度：环境→虚拟环境→框架→权重 ███░ 42%
   装好后：[启动] [停止] [更新] [卸载] [实际操作测试]
      → 出现在「快速操作模型」下拉里（local-laya · 分类器）
```

## 三、说明文字怎么放（统一规则）

- 主界面只留：**功能名 + 一行状态 + 主按钮 + 真实错误**。
- 解释、来源、许可、路径、日志 → 收进右边的小问号 `?` 或「高级」折叠。
- **这些不能藏**：真的不能用（未安装 / 平台不支持 / 权限被拒）、许可未解决导致「下载不可用」、下载安装进度、会花钱或涉及隐私的话（音频出本机、按量计费）。
- 名字统一写「中文功能名（模型名）」：**本地快速模型（Laya）**、**本地语音识别（SenseVoice）**、**快速操作模型（原生 Jev / System One）**，不再只写 Laya / SenseVoice 让人猜。
- 小问号要能用鼠标悬停、点一下、触摸、键盘 Tab 聚焦打开、Esc 关掉（现在键盘打不开，会一起修）。

## 四、需要你点头的一件事（另一件已定）

1. **语音默认值**：以前是「配了就用」，之后改成「未配置」——你第一次去语音配置页点一下「使用这个」才生效。这样不会在你不知情时用到云服务花钱。如果你更希望「本地装好就直接用、只有云才需要确认」，说一声。
2. ~~合并入口~~ **已定：这次不合并**。「固定地址 / 入口」「下载与组件」仍是独立入口（避免功能丢失），只做分组 + 新增语音配置。

## 五、这次不会动的东西

你的模型服务地址 / Key、已声明的语音模型、每个助理的模型与思考强度、记忆后端（全局 + 每助理覆盖）、权限档位、技能启用、定时任务、主题与语言——**全部原样保留**，只换位置和文案，不删功能、不重置配置。

# 发出去、助理还没看到的消息可以撤回

## 要什么
消息发出后，助理还没开始处理（单聊里运行中插话显示「等当前这一步做完送达」、群里还在排队没轮到）时，可以撤回：撤回后助理永远看不到这条，界面上这条显示「已撤回」（像微信）。助理已经看到的就不能撤回（按钮不出现）。

## 做法（先查再定）
- 单聊插话走 Pi `steer`：先查 Pi 公开接口能不能把还没交出去的 steer 消息拿掉（不能改 Pi、不用私有接口）；不能的话，插话先在我们这边排队，等工具结束、真正要送进 Pi 时再送（撤回 = 从我们的队列里删）。
- 群里：用户消息还没被任何成员读到（游标没到）之前可撤回，复用 `rooms/queue.ts` 的撤回排队。
- 界面：消息气泡上「撤回」（还没送达时才有），复用现有消息菜单 / `ContextMenu.tsx`；撤回后显示灰字「你撤回了一条消息」，可以「重新编辑」放回输入框。
- 和「长命令转后台」一起做（都在插话链路上，见 [background-commands.md](background-commands.md)）。

## 测试
单测：未送达可撤回、已送达不可撤回、撤回后助理收不到；e2e（Mock）：运行中插话后点撤回，助理回答里没有这条。

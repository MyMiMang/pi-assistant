# 助理自己整理人设

## 用户要的
用了一段时间后，让助理自己把「用户希望我怎么做事」整理进「人设与偏好」。
用户拍板（0031）：**只做手动按钮**（不在后台定时跑、不花额外的钱）；整理结果**先给用户看，用户采用并保存才生效**。

## 怎么做
- 入口：助理详情 › 资料，「人设与偏好」输入框旁一个按钮「让它整理」（`?` 说明：读最近和你的对话，把你反复提到的要求整理进人设，不会直接改，采用后点保存才生效）。
- 服务端 `POST /api/agents/:id/persona-review`（放 `routes/agents.ts` 或新 `routes/persona-review.ts`，纯逻辑单独成文件便于单测）：
  1. 取这个助理最近的单聊对话里用户消息和助理回复（按时间倒序，限条数 / 总字数，比如 80 条、3 万字；群聊消息不取，那里的话不一定对它说的）。
  2. 带上当前人设，用**这个助理自己选的模型**（找不到 / 本机渠道没注册上就按现有规则报中文错，不换默认模型）做一次补全，复用 `models.complete`（vision.ts 已有这种用法）。
  3. 让模型输出 JSON `{ persona: string, changes: string[] }`：新人设全文 + 几条大白话「改了什么」；没有要补充的就 `changes` 为空、`persona` 原样。
  4. 不写库，只返回结果。
- 提示词要点：保留原人设里仍然成立的内容；只加入用户**反复**提出或明确纠正过的做事方式（语气、格式、流程、禁忌）；不写用户个人事实（记忆系统负责），不写一次性任务内容；中文、简洁、不超过 1500 字；不编造。
- 前端：结果显示在输入框下方，新旧对比（至少列出 `changes`，人设全文可展开），按钮「采用」= 把新内容填进资料草稿（用户还能改），**仍需点「保存资料」才写入**；「放弃」= 关掉。加载中一个状态，出错一行中文。没有变化就提示「没发现需要补充的」。

## 不做
- 后台定时整理、自动写入、历史版本。
- 群聊消息、其他助理的对话。

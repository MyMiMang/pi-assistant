# 本地语音识别改为可选模块

> 取代 [default-local-voice.md](default-local-voice.md) §4–§5 和 [default-stream-contract.md](default-stream-contract.md) §1.2 的「新鲜用户首次启动自动后台准备」。流式协议、模型目录、安装链路都不变。决策见 [0013](../decisions/0013-local-voice-optional.md)。

## 1. 为什么
- 以前新装的用户一启动服务，就会在后台自动下载约 290 MB（共享运行环境 + 默认流式模型）。很多人只用云端语音，或者根本不用语音。
- 用户要求：语音拆成可选模块，默认不装，需要时在 设置 › 语音 里装；云端语音不依赖它。

## 2. 现在的行为
| 情况 | 行为 |
|---|---|
| 新装 / 升级上来、没装过本地语音 | 什么都不下载。设置 › 语音 › 本地 显示模块卡：「本地语音识别 · 可选模块 · 未安装」+ 一行说明 + **模型选择器**（预选目录默认「本地流式听写（中英双语）」）+「安装所选模型」 |
| 点「安装所选模型」 | `POST /api/local-models/asr/default-voice/install` body `{ modelId }`（窄接口，只认目录里的模型；手机已配对也能点）→ 只装这一个模型（+ 第一次的共享运行环境），统一下载 job `asr:<modelId>`，进度与「下载与组件」同一个 |
| 安装中 | 卡片写明在装哪个模型 + 真实阶段 + 百分比 + 「取消安装」；取消后回到「未安装」，不会自己重启 |
| 安装失败 | 哪个模型 + 原因 +「重试安装」（不带 modelId，服务端重试失败的那个）；也可在选择器里改选别的再「安装所选模型」 |
| 装好 | 用户亲手选定的模型 → 服务端 CAS 设为语音来源（安装期间来源没被改过才写，改过就不覆盖）；没切成时卡片给「设为语音来源」（复用 `setVoiceSource`） |
| 没装、点麦克风 | 不下载、不建会话，提示「请先在设置 › 语音 里选一个云端模型，或安装本地语音」+「去设置」 |
| 云端来源 | 完全不受影响；云端页不显示本地模块卡 |

- 其他本地模型（SenseVoice / Paraformer / Whisper…）不再折叠：没装任何模型时它们都在模块卡的选择器里；下方卡片只显示所选模型的详情（许可、大小、导入），不放第二个下拉 / 安装按钮。装过任意一个后下方恢复完整的切换 / 安装 / 管理（原来的选择器，保留 f14b6d7「停在已保存的模型」）。
- 旧后端（来源接口没给 `defaultVoice` 块）没有模块卡：下方卡片保持完整，不把用户卡在没有按钮的页面。

### 2.1 先选再装
- 选择器复用 ui.tsx 的 `Select`（新增可选的 `desc` 一行说明）、`useLocalAsrCatalog` 的目录和 `localAsrPick`（安装前「推荐」位换成模块当前模型：正在装 / 装失败的那个，否则目录默认），没有另做一份清单。
- 每项：名字 + 一行「适合什么」（目录新增 `suits` 字段，服务端数据，前端不写死）+ 右侧「约 X MB」。
- 大小 = 权重 + 共享运行环境估算（`catalog.runtime.downloadBytes`，约 95 MB）；运行环境所有模型共用、只算一次：装过任一模型（`runtime.present`）后只算权重。都是估算，界面写「估算」。
- 模块状态（`defaultVoice` 块）跟着「模块当前对应的模型」走：新增 `modelId` / `modelName`，顺序 = 正在装 → 正在用的已装模型 → 任一已装 → 装失败 → 目录默认；`defaultModelId` 仍是目录默认。
- 窄接口泛化，不另开新接口：install / cancel 都可带 `modelId`；未知 404、本平台不可装 400、非字符串 400、忙 409；省略 = 模块当前对应的模型（旧客户端、输入栏的重试 / 取消照旧可用）。仍不走 `localOnly`，手机（已配对）可用。
- 采用规则：带 `modelId`（用户亲手选定）→ `install_and_use` + `adoptIfUnchanged`，只要安装期间来源没变就写成它（CAS 版本号）；不带 → 原规则，来源从未设置才写。
- 「下载与组件」页里的 `asr:<modelId>` 行照旧，可以从那里装 / 取消。
- 删除：启动时 `ensureDefaultVoiceAutoPrep`、`voiceDefaultInit` / `voiceDefaultOptOut` 两个标记和资格判定（老用户库里残留的这两个键不再读取，无害）。

## 3. 安装包
- 运行环境（uv venv + sherpa-onnx wheel）和权重**从来不随安装包分发**（许可未确认，见 default-local-voice §7 的 P2 口径），所以安装包体积基本不变；变化在于新用户不再被自动下载约 290 MB。
- `scripts/stage-app.mjs` 增加兜底检查：暂存目录里出现 `*.onnx` 或 `sherpa-onnx` 就让打包失败，防止以后有人把运行环境 / 权重拷进安装包。
- 安装包里只剩本地语音的服务端代码（`local-asr/` + `voice/` 约 260 KB 源码）和前端界面，按需安装时要用到，不能去掉。

## 4. 不做
- 不把 `local-asr/` 代码本身做成可下载插件（体积小，拆成插件只会多一套加载机制）。
- 不改流式协议、目录、许可口径；不随包内置权重。

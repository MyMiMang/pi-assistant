# 聊天里的查看类面板也进侧栏

接 [file-preview-side-panel.md](file-preview-side-panel.md)。文件预览侧栏已经有「放大」按钮（打开成大窗口），这次把它推广成通用的侧栏。

## 哪些进侧栏、哪些保持弹窗
原则和 Claude 一样：**要边看边聊的内容进侧栏；要你填一下、确认一下的小操作保持弹窗**（侧栏里放一个只有一行输入框的表单反而不好用）。

| 入口 | 现在 | 改成 |
|---|---|---|
| 文件预览 | 侧栏（已做） | 不变 |
| 聊天顶部「执行 N」：帮手运行概览（`Subagents.tsx` `SubagentTasks`） | 弹窗 | 侧栏 |
| 群顶部「任务」看板 + 任务详情（`WorkItems.tsx`） | 大弹窗 | 侧栏 |
| 群顶部「项目」（`RoomWork.tsx`） | 弹窗 | 侧栏 |
| 「提醒」（`Proactive.tsx`） | 大弹窗 | 侧栏 |
| 整理上下文、重命名、新建、删除确认、群设置、设置、设备请求、导入技能、主题设计 | 弹窗 | **保持弹窗**（都是填写 / 确认类） |

## 做法
- 新组件 `SidePanel`（新文件 `components/SidePanel.tsx`），**用法和 `Modal` 一样**：`<SidePanel open onClose title testId>{内容}</SidePanel>`。上面四处只把 `Modal` 换成 `SidePanel`，内容和各自的状态都不动。
  - 窗口够宽（`resolveLayout().previewDocked`，规则不变）：内容通过 portal 渲染进聊天右边的侧栏槽位；
  - 放不下（手机、窄窗口）：直接渲染成原来的 `Modal`，行为一点不变；
  - 「放大」：同一份内容改成渲染进 `Modal wide fixed`（大窗口），关掉大窗口就整个关闭。
- 同一时间侧栏只显示一个：打开新的（文件或面板）时，旧的调用它自己的 `onClose`。
- 文件预览侧栏改用同一套：`FilePreviewDock.tsx` 的外壳（拖动调宽、Esc 规则、切换对话自动关、信息面板让位）挪进 `SidePanel` 的槽位组件里共用，不保留两套。
- 侧栏顶部统一：标题、「放大」、×。文件预览保留它自己的下载按钮。
- 宽度共用 `previewW`。

## 测试
- e2e：桌面宽窗口下，执行概览、任务看板（含点进详情）、项目、提醒都在侧栏打开，聊天区仍可见；打开文件会替换当前面板（旧面板关掉）；「放大」变大窗口；390 窄屏这四个仍是弹窗。相关的已有 e2e（找引用这些 testId 的脚本）继续通过。

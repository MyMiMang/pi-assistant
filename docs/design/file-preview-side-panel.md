# 文件预览改成聊天旁边的侧栏

## 要什么
像 Claude 的 Artifact 面板：点开文件，聊天区右边出现一栏显示文件，聊天还能继续看、继续打字；再点别的文件，侧栏换成那个文件；点 × 关掉。

## 做法
复用现有的 `FilePreview.tsx`（工具栏 + 各类视图）、`layout.ts`（宽度偏好、停靠计算）、`Resizer`（拖动调宽），不另起一套预览。

- **组件拆分**：把 `FilePreviewHost` 里「工具栏 + 内容」抽成一个内容组件，弹窗和侧栏都用它，只是外壳不同。各类视图不动。
- **宽度偏好**：`layout.ts` 加 `PREVIEW = { min: 360, max: 1100, def: 560 }` 和 `previewW`（按设备存，和 `sideW / paneW` 一样）。
- **能不能停靠**：`resolveLayout` 加 `previewDocked`：窗口宽度减去左栏宽度后，至少能给聊天区留 `CHAT_MIN`、给侧栏留 `PREVIEW.min`，才停靠；侧栏实际宽度 = `min(previewW, 可用宽度 - CHAT_MIN)`。
- **停靠时**：侧栏放在聊天区右边（`.pa-preview-wrap`，左边一个 `Resizer` 拖动调宽、双击恢复默认、收起就是关闭）。侧栏打开期间右侧信息面板先让位（不同时显示）；关掉侧栏，信息面板按原来的开关状态回来。
- **不能停靠时**（手机、窄窗口）：保持现在的全屏弹窗，行为一点不变。
- **工具栏**：文件名、类型和大小、下载、「放大」（打开成现在的大弹窗）、关闭。
- **切换**：侧栏开着时点另一个文件，直接换内容；切换助理 / 群 / 对话时自动关掉侧栏。
- **Esc**：焦点不在输入框 / 可编辑区域时，Esc 关掉侧栏；在输入框里打字时 Esc 不关。
- **图片**：仍然走 `ImageViewer` 全屏查看（不进侧栏）。
- **主题**：侧栏背景、边框用和信息面板一样的变量（`--panel`、`--line`），四套主题、深浅色都要正常；macOS 桌面程序顶部标题栏留白要和信息面板一致（`macos-titlebar.css`）。

## 测试
- 单测：`resolveLayout` 新的 `previewDocked` 和宽度计算（宽窗口停靠、窄窗口不停靠、左栏收起时的边界）。
- e2e：`e2e/file-preview.mjs` 桌面视口下改成验证侧栏（在聊天右边、聊天区仍可见且宽度 ≥ CHAT_MIN、拖动调宽生效、换文件换内容、「放大」打开弹窗、× 和 Esc 关闭、输入框里按 Esc 不关）；390 窄屏仍是弹窗；原有各类型断言继续通过。

# 助理与群成员详情按功能分类

状态：2026-10-18 已实现并完成定向验收，未打包。当前公开 beta.32 不含本次重排。最终类型、55项纯检查、build、新分类6组/既有成员8组浏览器回归通过；主核16张最终图。原始日志、失败修正和未验边界见 [验收记录](../../progress-snapshots/agent-details-functional.md)。

用户反馈：点击助理/群成员后详情分类不合理，思考强度难找。共享 InfoPane 调整，保持所有配置作用域、权限与运行逻辑。

| 分类 | 内容 |
|---|---|
| 概览 | 用量、主模型/思考强度摘要及跳转、后台任务数量 |
| 模型 | 主模型、思考强度、请求 Fast 分行可见且即时保存；图片模型；子代理候选池/强度/任务上限 |
| 资料 | 头像、名字、擅长、人设、保存/删除；详情内不再包含模型或电脑设置 |
| 能力 | 技能启用和扩展（MCP/扩展包） |
| 任务 | 二级标签：后台任务、定时任务、主动跟进；原任务执行与记录复用 |
| 记忆 | 原记忆查询与后端选择 |
| 文件 | 原上传/交付与预览下载 |
| 电脑 | 用户电脑权限、助理电脑共用/单独、实时桌面和工作区 |

概览只是摘要与导航，详情内主模型唯一配置入口在“模型”。聊天输入栏保持既有两层紧凑弹层；管理页复用模型目录、ThinkingButton、FastButton 和原按助理串行写入，不新增配置存储。档位支持、跟随默认、合法降级、Fast独立与费用提示不变。私聊和群共用该助理配置，立即保存的字段后续请求生效；资料保留显式保存。

资料编辑在同一助理面板切分类时保持挂载；换助理/关闭面板沿用现生命周期，不将资料草稿共享给别人。不为保存资料发送 model/thinking/fast 字段。旧 settings/proactive/routines 导航键兼容映射到资料/任务对应二级页，更新侧栏编辑、技能空态和主动菜单实际入口。保留 info-tabs 自适应更多菜单与键盘路径。

验证以隔离服务与构建后的真实浏览器为主：单聊/群员入口；分类位置及不重复控件；模型/强度保存刷新、失败保留真值重试、Fast字段独立；资料切页保留、失败保留、保存不盖模型；子代理/图片/技能/定时/主动/记忆/文件/电脑可达；跨成员迟到响应；280面板/390视口、长名称、明暗主题及键盘。模型与权限设置不得触达生产配置，不调用付费服务。

## 必须保留的契约

- 设置属于助理；普通助理在私聊/所参与群聊共用，群专属助理在私聊/所属群共用。不引入每群覆盖。
- 主模型、思考强度和 Fast 即时保存，沿用 canonical 串行 writer、迟到响应与卸载守卫。资料仅显式保存资料字段，不发送 model/thinking/fast。
- 模型目录按已配置服务分组、可搜索、常用入口保留。目录第二层有足够宽高；加载、读取失败、未选择、真无思考、存储值到有效值降级分别呈现。
- Fast 关闭不附加 service_tier；请求、服务支持、响应回显、实际加速和费用分别表达。仅设置页变小控件，共享思考弹层原 44px 命中区和帮助不受影响。
- 画图保留全局默认/指定/关闭；子代理保留候选池多选、空池跟随聊天、独立或继承思考、并发和时长继承。摘要必须取真实状态，不建立第二套存储。
- 新建助理流程保留原有完整配置与默认；详情资料的固定保存模式不能影响创建和建群提议。
- 用既有主题与动效 token 表达颜色、控件质感、间距和状态；深浅内置主题、DIY 与减少动态效果继续生效。

# Pi Assistant v0.1.0-beta.64

这一版修了编程工具（尤其是 Antigravity）在长对话里「看不到你刚发的话」、很费额度的问题。

- **你发的消息不会再被截掉**：当编程工具接不上上一段会话时（比如出错重试、重启、换模型），Pi 会把之前的对话整理好重新交给它。以前是把整段历史原样塞进去，长对话可能有几十万字，Antigravity 一次只收约 7.5 万字，后面全被截掉，连你刚发的那句话都看不到。现在你这次发的消息一定完整，放在最后。
- **重发的内容小了很多，省额度**：历史里的工具结果只留开头和结尾（约 2000 字），中间注明「需要时重新调用工具查看」；之前用过的技能，正文不再重复带，只写文件位置，需要时工具自己去读。你和助理说过的话保持原文。
- **Antigravity 单条最多 6 万字**：超了会先省略最早的几段对话，并注明省略了几条。其他编程工具没有这个上限。

这一版测试过的：
- 用测试数据跑过单元测试，以及 Antigravity、Claude Code、Codex 和其他编程工具的浏览器测试。
- 还没有用真实的 Antigravity 在你装好的 App 里试过长对话。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

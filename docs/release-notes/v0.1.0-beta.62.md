# Pi Assistant v0.1.0-beta.62

这一版修了 Mac 上编程工具反复弹窗的问题。

- **不再反复弹「找不到用于储存 X 的钥匙串」**：在 Mac 上用 Antigravity 等编程工具时，以前会一次次弹出这个系统提示框。原因是 Pi 给每个工具单独准备了一个文件夹，工具在里面找不到你的钥匙串，存不了登录信息。现在工具能找到你的钥匙串，登录信息正常保存，不会再弹。这一版没有改你钥匙串的任何设置。

这一版测试过的：
- 用测试数据跑过单元测试，以及 Antigravity、Claude Code 和其他编程工具卡片的浏览器测试。在本机确认过：工具的单独文件夹里能找到默认钥匙串。
- 还没有用真实的 Antigravity 在你装好的 App 里试过。如果更新后还弹，告诉我是哪个工具。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

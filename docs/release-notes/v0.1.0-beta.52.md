# Pi Assistant v0.1.0-beta.52

这一版主要改群聊：有活在做时，不用你一遍遍说「继续」了。

- 群聊会自己接着推进：
  - 以前只有登记过、还没结束的「项目」才会自动推进。项目结束以后接着做的活（比如继续写剧本、做生成），每轮做完就停下等你说「继续」。现在只要导演派出去的活交回来了，就会自动叫导演安排下一步，不管有没有登记项目。
  - 以前每轮最多发言 8 次，导演派一波活、总结、再派一波活，就被「本轮已暂停（这一轮已经发言 8 次）」拦住。现在到了上限会先看这一轮有没有新进展：群里新发了文件、任务有变化，就接着推进；没有新进展才暂停，请你回复「继续」。
  - 防空转的保护还在：导演被叫醒以后如果还是没有新成果，就不再自动叫醒，提示你看一下。导演反复派同样的活不算进展。
- 修了两处自动测试：测试本身的毛病让检查一直报错，真正的问题被挡在后面没被发现。这两处都不影响你用的功能。

这一版测试过的：
- 群聊：用测试数据和模拟模型跑过单元测试和群聊的浏览器测试，包括「没有进展时到上限暂停 → 点继续」和「成员每次都交文件，到上限也不暂停」。
- 没有用真实模型实测过群聊的新行为，也没有在你装好的 App 里、用你自己的群测试过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

## v0.1.0-beta.11

**修复**
- **Windows 打开后显示「127.0.0.1 拒绝连接」**：Windows 版的后台服务一启动就退出了，这次修好了。用户名是中文、安装目录带空格也能正常用
- **Windows 上「操作这台电脑」的组件没装上**：首次启动时复制 cua-driver 失败，现在会自动重试，失败也不会留下半截文件

**改进**
- **启动时先显示「正在启动…」**：后台服务准备好之前不再出现浏览器的报错页。真的启动失败时，会说明原因，并提供「重试」「复制诊断信息」「打开日志文件夹」
- **端口被占用时自动换一个**：8787 被别的程序占着时会自动改用 8788 等端口，并记住下次接着用
- **日志会保存到文件**：Windows 在 `%LOCALAPPDATA%\com.piassistant.app\logs\server.log`，Mac 在 `~/Library/Logs/com.piassistant.app/server.log`，最多占 10MB
- **发版更稳**：每个版本都会先在干净的 Windows 和 Mac 上真的安装、打开一遍，确认能用才推送自动更新

## v0.1.0-beta.10

**新功能**
- **助理群聊**：把几个助理拉进一个群。你 @ 谁谁回答；不 @ 人时由「管理者」理解需求、分派给合适的成员，做完再总结。说一句目标就能让助理帮你建群（群专属成员、按活分配模型），觉得好用的成员可以复制到自己的助理列表
- **群里可以发图片和文件**：点回形针、粘贴截图、拖进来、手机上从相册/文件选都行。每个成员都能拿到附件，管理者派活时可以把附件交给指定成员，助理做出来的文件也会发到群里给其他人用
- **助理真正"看懂"附件**：支持看图的模型直接看到图片（iPhone 的 HEIC 在 Mac 上自动转换）；不支持看图的模型会交给「识图模型」描述（设置 › 模型 › 识图模型，默认自动选）。PDF、Word、Excel、PPT、文本会自动提取文字给助理，扫描版 PDF 会提示没有文字
- **图片生成**：设置 › 模型 › 图片生成，接入 OpenAI 兼容、百炼、方舟、Gemini、xAI 等，助理可以画图、改图，单聊群聊都能用
- **渠道里收发真正的图片和文件**：微信、飞书、钉钉、企业微信里直接收到原图/文件，不支持的格式自动转换或给下载链接；群聊里的审批和提问也会推送到你绑定的渠道，回复「批准」「拒绝」或点按钮就能处理
- **思考过程单独折叠**：模型的思考内容不再混进回复正文，App 里可以展开查看，渠道消息里自动去掉
- **操作你的电脑更可靠**：网页操作改用新的浏览器控制方式，按权限档位审批，上传下载只限工作区
- **桌宠**：可以在桌面上放一个助理小形象，随时看到它在忙什么
- **设置 › 关于与更新**：看当前版本、检查更新、更新内容和下载进度；更新时实时显示进度，失败会说明原因

**修复与改进**
- M 芯片 Mac 上「助理电脑」开机即退出的问题已修复（桌面镜像 0.1.3）
- 模型列表重新设计，自动从 models.dev 匹配上下文和输出长度；服务商嫌输出太长时自动调小重试
- 手机上聊天不再左右晃动，内容居中；窄屏下文字不再被挤成竖排，放不下的标签收进「更多」
- 「操作你的电脑」提示只在助理真的在操作时出现
- README 重写，列出用到的全部开源项目和许可证

> 从 beta.7 或更早版本升级时，旧版的更新程序可能看起来没反应，等几分钟或手动下载安装包装一次即可。

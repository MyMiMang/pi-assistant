# Pi Assistant v0.1.0-beta.55

这一版修的是：助理卡在某一步上，就永远停在那里。

- 以前助理调用的某个工具一直不返回（比如网页卡死了，读网页内容那一步就会一直等），助理会永远卡在这一步。这时候：
  - 点「停止」没用；
  - 你在群里发的话排在它后面，一直送不到，看起来像不理你；
  - 群里会反复冒出「项目反复卡住」的提示。
- 现在所有工具（浏览器、操作电脑、MCP、群工具、画图等）都统一加了两条保护：
  - 点「停止」马上结束正在做的这一步。
  - 一步工具累计 10 分钟没有返回，就放弃这一步，并告诉助理「这一步卡住了，换个做法或重试」，助理可以接着干活。等你批准、回答提问、接管页面的时间不算在 10 分钟里。
- 「项目反复卡住」同一种情况只提醒一次。之后有了新进展又卡住，才会再提醒你。

这一版测试过的：
- 用测试数据和模拟模型跑过单元测试，以及插话、停止、群聊相关的浏览器测试。
- 没有用真实模型、真实卡死的网页验证过，也没有在你装好的 App 里、用你自己的助理和群测试过。

如果你的助理现在正卡着：更新会在重启 App 后生效，重启本身就会把卡住的那一步清掉。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

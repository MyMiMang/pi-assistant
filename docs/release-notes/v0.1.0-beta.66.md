# Pi Assistant v0.1.0-beta.66

这一版修了 Antigravity 在 Pi 里总是提示「额度用完了」，可在 Antigravity 自己的 App 里却能正常用的问题。

- **Antigravity 能正常回复了**：原因不是账号，也不是额度。Pi 给模型的默认说明里有一句「运行在 pi 里」（running inside pi），Google 的 Antigravity 服务看到这句就直接拒绝整个请求，返回的错误却是「额度不足」。所以不管新建助理还是新开对话，都会报额度用完。现在交给 Antigravity 之前会去掉这半句，其他内容不变，其他模型渠道也不受影响。

这一版测试过的：
- 用你的 Antigravity 账号手动对照过：只带这半句的请求会被拒，去掉以后整段说明都能正常回复。
- 用测试数据跑过单元测试和 Antigravity 的浏览器测试。
- 还没有在装好的 App 里用新版本实际聊过，更新后可以直接在之前报错的对话里再发一次试试。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

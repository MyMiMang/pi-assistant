# v0.1.0-beta.83

在「设置 › 模型服务 › 编程工具 › Antigravity › 管理账号」新增 **Google 多账号登录**，现在支持同时通过 Google 登录和 RT 管理多个 Antigravity 账号。

- **用 Google 登录添加多个账号**：点击「用 Google 登录添加」会在独立环境中拉起官方登录流程；每个账号自动按邮箱收进同一个账号列表、加密保存，随时切换或移除未使用的账号，也可以切回原来的 Google 登录。
- **不干扰正在运行的任务**：新增 Google 账号在独立临时目录里完成，不影响当前正在使用的账号和对话，随时可以取消；同样不读取或修改你电脑上单独打开的反重力。

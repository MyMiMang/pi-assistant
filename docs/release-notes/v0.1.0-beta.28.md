# v0.1.0-beta.28

状态：候选，待打包发布。本轮构建**全部平台**：Apple 芯片 Mac（arm64）、Intel Mac（x64）、Windows（x64）、Linux 服务器版（x64 / arm64）。

## 手机聊天更快、更省

- 聊天原本已分页，本版把首屏批量从单聊 300 条、群聊 200 条降到最近 50 条；往上滑再按需加载，并避免停在顶部时连续拉完历史。
- 开启静态资源预压缩 + JSON gzip；首次连接的去重与上滑自动加载的保护也一起修了，网络差时不容易卡。
- 引用一条很久以前的消息时，**一次只取目标附近的一段窗口**，一步跳到，不会把中间的历史全塞进界面；窗口里来了新消息只提示数量，点「回到最新」就恢复最近一页。

## 语音输入：边说边出字、真实音量

- 本地语音识别改成**分段增量**：说话过程中就陆续把文字写进输入框，不用等整段说完再出结果；多段按说话顺序拼，中途某段失败只重试那一段，不会把已经出来的文字打乱。
- 输入条上的音量条改为显示**真实录音音量**，静音时接近零，停止后不残留假波形。
- 云端语音保持**整段一次请求**，不会因为增量把计费拆成很多次。
- SenseVoice 仍然在模型列表里，可以像其他模型一样一键下载安装（本地自用；不随 App 分发、商用未确认）。

## 聊天里的表格不再被裁

- 表格按窗口可用宽度排版、单元格内自然换行，最后一列不会再被裁掉；实在放不下时在表格自己那一块横向滚动，并给常显的滚动条，也能用键盘左右滚动。
- 代码块、长链接、图片和文件卡片都不会越过气泡边界。

## 子代理

- 思考强度选择移到输入栏工具栏，和主会话同一位置；页头不再重复出现。
- 页头可以直接切换同一主会话里的其他子代理（含已结束的），不用先回主会话。各子代理的草稿互不干扰。

## 界面一致性与动效

- 工具步骤（Steps）展开时显示**完整内容**，不再被固定高度截断；完成后自动收起，用户手动收起的不会被新步骤重新弹开。
- 下拉、弹窗、折叠统一了进入动效；开启系统「减少动态效果」时会关闭这些动画，但状态仍然看得清（加载指示停转仍留颜色、闪烁文字停止后不留透明字）。
- 设置里的下拉选择支持 ↑↓ + Enter、Esc 关闭、点外部关闭，操作后焦点回到按钮。
- **提问卡片（助理问你问题时的选项）改为一行一个**：整行都可以点，文字靠左，长文案自动换行，选中标记在右边；桌面和手机同一结构，已回答的历史卡片也一样。

## 基准测试（快速操作模型）

- 「实际操作测试」改成**点哪条测哪条**：不用先打开全局快速模型，从具体卡点直接测该模型。
- 快速操作模型列表会在模型目录变化时自动刷新，第一次打开就是最新的（不用退出重进）。

## 仍在设计、未包含的功能

- 七档思考强度主题滑块目前是交互设计稿，生产界面仍使用现有选择器。
- AI DIY 主题覆盖组件质感与动效参数的扩展仍待实现，不能把本版统一动效 token 当成已接通完整 AI DIY。

## 发布范围

- 这一版**恢复 Intel Mac（x64）**构建，并照常构建 Windows 与 Linux 服务器版。

## 本轮的验证范围（如实）

- 通过：两端类型检查与网页构建；定向服务端单测（手机聊天分页与压缩 31 项、Laya 基准与路由 56 项、语音 133 项）；发布范围逻辑单测 5 项；浏览器 e2e 六个脚本（手机聊天分页 8 项、表格溢出全套、子代理切换、UI 一致性与动效、语音增量、语音输入）全过；页面截图人工核对。
- **未在本机验证**：Windows / Linux / Intel Mac 实机安装与启动；真实 iPhone 与隧道；真实麦克风；真实云模型与计费；全量单测与全量 e2e。
- Mac 安装启动冒烟、Windows 静默安装冒烟与 Linux 构建由 CI 在 tag 触发时执行；**平台构建成功不等于该平台实机已测**。
- 若某个平台的构建或冒烟没通过，Release 会停在草稿、不会公开，已安装用户不会收到更新。

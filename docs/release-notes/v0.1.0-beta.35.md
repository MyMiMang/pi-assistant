# Pi Assistant v0.1.0-beta.35

已于2026-10-20 19:04（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.35)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

- 群任务卡住、反复退回时，由管理者自己想办法，不再一卡住就问你「换个方法 / 改派 / 暂停」：
  - 先由管理者看执行记录、找原因，带着纠正让负责人重做，或者把任务拆小；
  - 同一个负责人重做 3 次还没通过，或者管理者介入后仍然没有进展，会最后提醒一次管理者：不能再原样重做，必须换做法（改派给别的成员、拆小或自己接手）。改派给新成员后重新计数；
  - 换了做法还是不行，任务标为「已用尽办法」，管理者会在群里跟你说清楚问题是什么、试过什么、需要你帮什么，同时推送给你。这是通知，不是提问；你可以在任务看板上继续、改派或重开。
- 管理者按群目标自己做大部分决定。只有需要你才能给的东西（批准一个操作、登录账号或凭据、只有你有的资源），或者超出群目标、它无权拍板的决定，才会来问你，并说清要你做什么。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离的临时数据、Mock 模型和 Chromium 交互；真实模型下管理者会不会按规则换做法、向你说明得清不清楚，还需要在实际使用中确认。

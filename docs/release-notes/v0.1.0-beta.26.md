# v0.1.0-beta.26：Laya 下载看得见、本地语音多模型、主题设计显示并可选模型

> 状态：**发布准备，尚未公开**；按本轮已有授权完成验证后直接推送并打包，构建及 Mac 安装冒烟通过后公开。范围为**仅 Apple 芯片 Mac（arm64）**；Intel Mac、Windows、Linux 本轮不构建。

## 下载 Laya 现在看得见、能取消

- 以前点「一键安装 Laya」，「下载与组件」里看不到这个任务，还会红字报 `符号链接越界：.gitattributes / README.md / encoder/config.json`，也没有进度条。
- 原因有两层：① 校验时把 Hugging Face 缓存里**合法的符号链接**（`../../blobs/<sha>`）误判成越界；② Laya 当初没有登记进下载面板。
- 现在：校验按缓存根判断，只拦**真正越出缓存**的链接；`README` / `.gitattributes` 这类辅助文件缺失不再算失败，权重与 `encoder/config.json` 仍逐个严格校验；校验后物化成普通文件再启用。
- Laya 与其它组件共用**同一个下载面板**（「下载与组件」里 `本地模型` 分组），有真实字节进度，**可取消**，失败有可见原因并可重试；「操作这台电脑」的 Laya 卡和下载面板读到的是**同一个任务**。

## 本地语音可选多个模型（不再硬编码）

- 语音配置页按电脑档位推荐「轻量 / 均衡 / 高质量」，列出模型大小和运行内存估算（**估算，不是跑分**），可一键「安装并使用」。
- 正式提供 **5 个可下载**模型：Paraformer 中文（Apache-2.0）、Whisper base / small / turbo / large-v3（MIT）。
- **修掉了硬编码**：以前不管选哪个模型，都去 SenseVoice 的仓库取权重，导致 0 文件 / 校验失败；现在按**所选模型自己的仓库与版本**下载并逐文件校验。
- 只装 ≠ 改来源：「安装并使用」由后端在装完且期间你没改选时，才把语音来源切到本地；已有模型用「使用这个模型」切换。
- **SenseVoice 权重许可仍未确认**，与上一版一样**默认不提供下载**，只支持自行导入合法权重（旧版导入入口默认收起）。

## 用 AI 设计主题时能看到并选择模型

- 设计面板顶部新增「使用模型」：显示本次实际使用的模型（没显式选时标「默认模型 · xxx」，不静默跑），也可以直接在面板里换一个**已配置的聊天模型**。
- 换模型**只作用于这一次生成**：不改助理主模型 / 模型池 / 全局默认。
- 带参考图时只列**支持看图**的模型；当前模型不支持会保留图片并禁用生成，提示换模型或去图。
- 显式选了不存在 / 已删 / 缺凭据的模型会**直接报错、不发请求、不偷偷换成别的收费模型**。

## 沿用 beta.25、本版没有变的

- **Enter 仍然默认发送、Shift+Enter 换行**（可在 设置 › 聊天与输入 改）；沿用中文输入法确认回车保护，真实 Safari / iPhone 输入法行为仍待验证。
- 设置按功能分组、语音来源显式选择、Jev 自动识别、常用模型保留原渠道等照旧。

## 已实测 / 未验证（如实）

- **已真实跑通**：Whisper base（160.6MB）与 Paraformer 中文（243.4MB）完成真实权重下载、每个文件 SHA256 校验、识别进程启动和真实转写；续跑复用已校验缓存，并验证共享运行环境复用。英语样例 Whisper 命中关键片段；中文样例 Whisper base 输出偏少字，Paraformer 命中关键片段但末字与官方示例有差异（官方期望「你」实测「嗯」）——**如实说明，不夸质量**。切换模型后进程不同、停止后回收；卸载一个不影响另一个。
- **未验证**：Whisper small / turbo / large-v3 **未做真实安装及推理验证**（后两款约 1~2GB）；Windows / Linux / Intel Mac 未实机；运行速度 / 峰值内存只采到**单次样本**，不作为性能结论或电脑推荐；真实云语音识别与云端大模型、真实麦克风、Laya 的真实大权重端到端、真机安装包都未验证。
- 下载的模型权重**不随产品分发**，按需从固定版本拉取并校验；许可与署名见 `THIRD_PARTY_NOTICES.md`。

本版仍只提供 Apple 芯片 Mac（arm64）安装与自动更新包；应用没有 Apple Developer ID 签名，更新后可能需要重新授予系统访问权限（历史问题，与本次改动无关）。

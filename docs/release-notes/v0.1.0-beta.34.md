# Pi Assistant v0.1.0-beta.34

已于2026-10-20 08:20（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.34)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

- 「子代理」改叫「帮手」：界面和助理跟你说话时都用这个词。后台任务、定时任务、主动巡检和群任务的每次运行，都是一个帮手，统一在聊天顶部的「执行」里查看、插话、停止或继续。帮手可以再派一层帮手，但不能无限往下派。
- 服务重启更安全：重启时如果帮手有操作已经发出、但不知道结果（比如命令跑到一半），不再自动重放，而是标成「中断待核验」，你看过之后点「继续」，它会先核对做到哪一步再接着干，不重做。
- 帮手卡住时由助理自己处理：还在慢慢跑的命令、还在输出的模型不算卡住，不会被打断；真卡住了，助理会看记录、带着纠正重来、换做法或改派，办法用尽再给你一份失败总结。只有需要你批准、登录或做取舍时才来问你，不再弹「继续等 / 停止」这种卡片。
- 群聊协作：管理者把任务交给负责的成员，成员在自己的会话里干活，干完管理者核验，通过才算完成，不通过就退回修改。群里的「任务」看板按「等你决定 / 卡住 / 进行中 / 已完成」分组，需要你决定的放在最上面，可以直接回答。可以一键暂停全部任务；停掉群聊不会停掉正在做的任务。
- 群里其他助理默认只看帮手的结论，需要时可以点名查看某个帮手的完整过程；你在 App 里点进任何帮手都能看到全部步骤。
- 本地语音识别改成可选模块：默认不安装，启动时不再自动下载约 290MB 的文件。需要时在「设置 › 语音 › 本地」先选模型再安装，每个模型写明适合什么和大约多大。
- 桌面 App 里可以直接把文件拖进聊天框，和点「上传」一样，单聊、群聊都行。
- 凭据更安全：如果系统钥匙串里的主密钥读不到（比如访问弹窗点了「拒绝」、钥匙串锁着），App 会停下并告诉你怎么处理，不再悄悄换一把新密钥，导致之前保存的 API Key 全部失效。
- 修复：「?」说明气泡有时挡住下面的按钮；外观 DIY 生成时「加图片」按钮位置跳动；下载组件时进度统计偶尔出错。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离的临时数据、Mock 模型和 Chromium 交互；拖文件进聊天框、钥匙串读不到时的提示、群里帮手协作，都还需要在真机和真实模型上确认。

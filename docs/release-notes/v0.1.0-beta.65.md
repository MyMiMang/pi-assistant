# Pi Assistant v0.1.0-beta.65

这一版让编程工具（尤其是 Antigravity）在长对话里更省额度，出错后也更容易接着用。

- **历史太长时先整理再继续**：编程工具接不上上一段会话、要把历史重新交给它时，如果太长（Antigravity 超过 6 万字），Pi 会先把之前的对话整理成一份摘要，再带上「摘要 + 最近几轮」重新开始。以前是直接省略最早的对话，前面聊过的事可能就丢了；现在前情会以摘要的形式保留。整理过以后还是太长，才省略最早的几段。
- **出错后不再整段重发**：编程工具一个字都没回就出错时（比如服务方临时限流），会保留这段会话，下次只发你新说的话，不用把整段历史再塞一遍，省额度。

这一版测试过的：
- 用测试数据跑过单元测试，以及 Antigravity、Claude Code、Codex 和其他编程工具的浏览器测试。
- 还没有用真实的 Antigravity 在你装好的 App 里试过长对话。
- 已知情况：出错后接着用时，编程工具那边的记录里可能会出现一条重复的你的消息，不影响回答。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

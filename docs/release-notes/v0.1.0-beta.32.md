# Pi Assistant v0.1.0-beta.32

- 建群、加成员的提议卡现在按模型服务分组，显示你设置的中文服务名，并保留角色推荐。新成员可直接选择思考强度，档位跟随真实模型能力；换模型会清楚显示合法降级，确认后保存生效。
- 点群成员默认打开的「概览」即可修改模型与思考强度，也可恢复跟随默认。改动用于后续请求，同一助理的私聊和群聊共用。设置页继续使用显式保存，保存失败保留草稿；加入已有助理不会重设它的配置。
- 修复模型/强度保存后显示旧值、失败没有提示、迟到响应覆盖新配置的情况。加载失败可重试，编辑其他资料不会覆盖模型设置，Fast 开关保持独立。
- 自动建议创建技能时，先讲清技能名称、做什么、以后什么时候用、能给你什么，再询问是否保存。说不清用途、只有“继续”等泛泛指令或任务明显失败时不提。用途总结使用当前模型，会产生正常用量；可在「设置 › 技能库」关闭。
- 技能提议卡等待回答时助理会恢复空闲，不会一直占着执行。你同意后才继续查重与保存；保留更新差异审批、拒绝和不再提醒。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离 Mock 服务、真实 Pi 会话和 Chromium 交互；不代表已完成所有系统与物理手机的任务验收。此前服务请求超时的具体原因仍未确证，本版没有通过延长超时、降低思考或额外重试来掩盖问题。系统电脑操作授权跨更新的持久性仍受稳定签名与系统 TCC 限制。

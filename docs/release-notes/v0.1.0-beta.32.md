# Pi Assistant v0.1.0-beta.32

已于2026-10-18 16:29（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.32)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

- 模型请求失败时直接显示具体错误，不再只剩一个空“引用”。明确区分额度耗尽、临时限流、登录或 Key 问题、网络与超时；服务没给原因时如实说明未知。额度耗尽提示等待恢复或换可用模型，服务详情在手机上也能展开查看。
- 修复后台任务遇到模型错误却显示“已完成、结果为空”的情况：现在记为失败，并在原对话直接给出原因；显示报错不再依赖一次新的模型请求。
- 群聊新增轻量「任务」看板：长期责任与单次执行分开，执行结束不再等于任务完成。管理者派活、成员交付、读取产物核验仍在原群；指出问题后修订原任务、继续处理，不必手动维护两套记录。支持状态筛选、历史、分页及手机窄屏。
- 修复子代理完成或超时的通知一律让主会话停下的问题。明确且仍获授权的目标可在核对进度与副作用后继续；保留真正停止、权限、费用与重试上限，不靠猜需求，也不盲目重放结果不明的执行。
- 主动巡检/跟进可回到相关对话实际推进，不只发送提醒。推进队列、停止和恢复持久保存，排队不冒充已经完成；开关、去重、频率及执行上限仍有效。新增有后果的范围先确认，外部网页/文件不构成授权。
- 未开启或未实际请求 Fast 时，普通服务 default 回显不再每条都显示 Fast。保留实际历史请求和外部 priority 的来源说明，不据回显推断加速或计费。
- 建群、加成员的提议卡现在按模型服务分组，显示你设置的中文服务名，并保留角色推荐。新成员可直接选择思考强度，档位跟随真实模型能力；换模型会清楚显示合法降级，确认后保存生效。
- 点群成员默认打开的「概览」即可修改模型与思考强度，也可恢复跟随默认。改动用于后续请求，同一助理的私聊和群聊共用。设置页继续使用显式保存，保存失败保留草稿；加入已有助理不会重设它的配置。
- 修复模型/强度保存后显示旧值、失败没有提示、迟到响应覆盖新配置的情况。加载失败可重试，编辑其他资料不会覆盖模型设置，Fast 开关保持独立。
- 自动建议创建技能时，先讲清技能名称、做什么、以后什么时候用、能给你什么，再询问是否保存。说不清用途、只有“继续”等泛泛指令或任务明显失败时不提。用途总结使用当前模型，会产生正常用量；可在「设置 › 技能库」关闭。
- 技能提议卡等待回答时助理会恢复空闲，不会一直占着执行。你同意后才继续查重与保存；保留更新差异审批、拒绝和不再提醒。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离 Mock 服务、真实 Pi 会话和 Chromium 交互；不代表已完成所有系统与物理手机的任务验收。此前服务请求超时的具体原因仍未确证，本版没有通过延长超时、降低思考或额外重试来掩盖问题。系统电脑操作授权跨更新的持久性仍受稳定签名与系统 TCC 限制。

## v0.1.0-beta.18

这一版按你的纠正重做「完全权限」的审批：**选了完全权限就全部不弹审批**。只含权限相关改动，图片全屏预览、发送快捷键、子代理卡片排版等仍在验证中的改动不带入本版。

**完全权限 = 应用层不再弹审批**
- 之前完全权限下，关机、删除、改系统设置这类「受保护操作」还会单独弹一次审批。现在只要档位是**完全权限**（已开启「操作这台电脑」+ 允许这个助理 + 没暂停），应用层就**不再创建任何审批**：受保护的系统动作，以及发送邮件、提交表单、连接浏览器、上传下载、新建定时任务、改技能等有后果的动作，都直接执行。
- 主会话、子代理、后台任务都用这个助理当前的档位，所以同一个判定到处生效；暂停或把档位调低，下一条动作立刻回到原来的审批规则。
- 所有应用层审批集中在同一个入口（`requests.approval`），不再出现「有的地方问了、有的地方没问」的遗漏。

**仍然拦得住的东西（没有为了免审批删掉安全限制）**
- 凭据和密钥文件（`.ssh`、`.aws`、`auth.json`、浏览器 Cookies 等）继续**直接拒绝**，任何档位都不例外。
- 一键暂停、降权、关闭开关立刻生效；「只看」档位仍然不能点击输入；「限定」档位仍然只能操作你勾选的应用。
- 宿主操作系统的权限弹窗（macOS 辅助功能 / 屏幕录制、钥匙串等）仍然要你自己点；网站上的登录、短信 / 图形验证码、人机验证仍然要你本人完成（助理会请求接管）。
- 后台主动巡检（心跳任务）仍然不会自主执行需要审批的操作。

**需要你知道的一点**
- 权限计划的说明文字变了，出于安全考虑**不会自动放行**：如果你之前已经开启「操作这台电脑」，升级后需要到 设置 › 操作这台电脑 重新查看并确认一次权限计划，Cua Driver 才会重新启动。其他档位的设置不受影响。

**当前限制**
- 完全权限下助理是以你本人的身份运行，真的会直接执行关机、删除系统目录、改防火墙这类操作，也会直接发邮件 / 提交表单，请只在信任的助理上开启；一键暂停随时可用，所有动作都会记录。
- 安装包仍未签名：macOS 首次打开要右键 → 打开，Windows 会有 SmartScreen 提示（选「仍要运行」）。

# Pi Assistant v0.1.0-beta.46

这一版主要让助理更主动：以前巡检几乎不做事，现在默认会自己把能做的事做掉。另外，长命令跑着的时候插话不用再等，发出去还没被看到的消息也可以撤回了。

- 助理会主动做事了（在「助理设置 › 任务 › 主动跟进 › 主动做事」里）：
  - 你交代过的事，以及你已经开始的事里看得出能帮上的一步（比如卡住的任务、明显的下一步），助理会直接去做，做完简短告诉你结果，不再只发一条「要不要我做」的提醒。
  - 你没提过的全新的事，只有对上你在「可以放心做的事」里写的规则才直接做，对不上就只提醒你。规则每条写一句大白话，比如「报告类任务卡住超过半天，可以直接重跑一次」。
  - 对外承诺、花钱、删改重要东西、改权限，仍然先问你，审批规则不变。
  - 三种模式：自动（默认）、试运行（只记成「本来会做」的卡片，你点「就这么做」才做，点「这类以后别做」它会记住）、关。主动等级本来是「关」的助理不受影响。
  - 「判断记录」里能看到助理每次主动做了什么、依据是什么、结果如何。
- 巡检能看到群了：助理在的群里你最近说的话、进行中的任务、卡住的事都在巡检范围内，它可以直接在群里接着推进（群里会先出一条小提示）。以前群里的成员如果没和你单聊过，根本不巡检，现在也会巡检。
- 巡检卡住超过 3 分钟就结束这一次，下次再来，不再一卡十几分钟。
- 群里约好的跟进，到点后直接在群里接着做（以前到点后回不了群）。群里约的跟进不受免打扰时段影响，单聊的跟进照旧顺延。
- 长命令跑满 5 秒会自动转到后台继续跑，这时插话马上就能送到，助理会先回你，命令跑完再接着处理。聊天里会出一条「后台命令结束」的小提示。每个后台命令最多跑 30 分钟；点「停止」会一起结束。帮手和后台任务里的命令照旧跑完再继续。
- 发出去、助理还没看到的消息可以撤回：气泡下面有「撤回」，右键或长按菜单里也有。撤回后显示「你撤回了一条消息」，点「重新编辑」原文会回到输入框。单聊和群聊都能用；助理已经看到的消息不能撤回。

这一版在隔离的开发测试环境里，用真实模型（DeepSeek V4.1 Flash）实测过：一条 20 秒的命令跑到一半时插话，3 秒内就送到了，助理先回答插话，命令跑完后接着汇报；巡检能看到群里的情况；群里约的跟进到点后在群里执行。

没有实测的：
- 助理在群里主动推进事情（只在模拟测试里验证过）。
- 助理电脑（Docker）里的长命令转后台。
- Windows 和 Linux 上的使用。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

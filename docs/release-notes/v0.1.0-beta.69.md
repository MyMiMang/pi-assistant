# Pi Assistant v0.1.0-beta.69

这一版让 Antigravity 能看图片，并修了「选的是 Gemini，却悄悄变成用默认模型」的问题。

- **Antigravity 能看图了**：给用 Antigravity 模型的助理发图片，它会自己调用看图工具查看图片再回答。以前这个渠道被标成不能看图，发图片它只能说看不到。原因是 Antigravity 的命令行只收文字、不收图片，现在改成让它通过工具去读你发的图片附件。
- **编程工具渠道没连上时，不再悄悄换成默认模型**：App 启动时，如果网络慢，Antigravity 等编程工具取模型列表可能超时，这个渠道就没注册上。以前选了它的助理会悄悄改用你的默认模型（比如 DeepSeek），你以为在用 Gemini，其实不是。现在：
  - 注册失败后会在后台自动重试（30 秒、1 分钟、2 分钟，之后每 5 分钟），连上就恢复；
  - 你发消息时如果还没连上，会先马上再试一次并等一会儿；
  - 实在连不上，就在对话里明确提示「暂时没连上，这一轮没有改用其他模型」，你可以稍后再发，或到 设置 › 模型服务 里点「重新检测」；
  - 帮手、群里的工作项、新建和修改助理也一样，不会悄悄换模型。

这一版测试过的：
- 在和你的 App 分开的测试环境里，用你的 Antigravity 账号给测试助理发了一张左蓝右黄的图片，它调用看图工具后正确答出两边的颜色。
- 用测试数据跑过单元测试，以及 Antigravity、Claude Code、Codex 的浏览器测试。
- 「没连上时明确提示」只在测试里模拟过，没有在真实网络超时的情况下实际看过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# Pi Assistant v0.1.0-beta.41

这一版主要修记忆，也让模型服务出问题时的提示更好懂：记忆里少了「助理说自己记下了」这类没用的条目，测试连接不再误报，额度用完或被限流时会直接告诉你大约几点恢复。

- 记忆更干净：
  - 只是让助理查记忆的那一轮，不再写进记忆。以前用真实模型时，「搜了记忆、找到几条」这种话会被当成新事实，越查越多。
  - 刚记下的事一定能被找到。
  - 召回结果里一模一样的句子只留一条。
  - 你说「记住……」之后，只保存你的原话，不再额外存一条「助理确认已存入记忆」。
- 助理回完话就结束「工作中」。一轮结束后的自动记忆写入放到后台进行，记忆服务再慢也不会让助理一直显示「工作中」。
- 「测试连接」现在会带上一个很小的工具定义，和真实聊天的请求一样。有的中转站只在请求带工具时才限流或冷却，以前测试会显示连接正常，聊天却失败；现在测试结果和实际使用一致。
- 额度用完、限流或「冷却中」的报错改成一句中文，并带上服务给出的恢复时间，例如「模型服务正在冷却……约 15:04:53 恢复：等一会儿再试，或换个模型」。服务返回的原文放在旁边的「?」或「查看服务返回的信息」里。聊天、各处的测试连接和记忆健康提示都是这样。
- 记忆设置里，如果备用模型和主模型在同一个渠道（同一个中转站或同一个 Key），会提醒你：额度用完或限流时它们会一起失败，起不到备用作用，建议换成别的渠道的模型。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

这一版用真实的 DeepSeek 中转模型在隔离测试环境里验证过：
- 记住和找回都正常，重启后也能找回。
- 说「记住」之后，没有再多出「助理确认」的条目。
- 群聊里告诉助理的事，会作为待核验草稿记下；在单聊里问时，助理能答出来，并会提示你这条还没确认。
- 测试连接正常。
「额度 / 冷却」的中文提示没有等到真实限流，是用模拟的报错验证的。

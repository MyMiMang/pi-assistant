# v0.1.0-beta.30

## 更紧凑的模型与思考强度菜单

- 点击聊天输入栏的模型入口，先显示当前模型、思考强度和 Fast 开关；点模型名再进入可搜索的完整列表，选完返回紧凑面板。
- 思考强度采用粗胶囊渐变轨道和白色实心圆钮，上方显示当前档位及实际模型。拖动只预览，松手才保存；取消、失焦和 Esc 不写入半途选择。
- 保留模型支持的实际档位、子代理跟随、键盘操作、手机窄屏、主题动效和减少动态效果设置。

## 聊天请求级 Fast 闪电

- 紧凑面板左上角可以开启请求级 Fast，独立于思考强度，不换模型、不降低思考档位。
- 当前可向 OpenAI Responses、Chat Completions 和 Codex 协议附加 `service_tier: priority`。Codex 登录路径可以携带参数，但具体账号、模型、服务商是否接受、实际是否加速尚不能保证；Claude 原生接口暂未接入。
- 开关从下一次请求起持续生效，直到更改设置；已发出的请求不受影响。关闭只停止本开关附加参数，不覆盖服务原有档位。
- 子代理默认跟随所属助理，也可以单独设置或恢复跟随。保存失败回滚，迟到的旧请求不覆盖新选择。
- Fast 可能增加费用，具体以服务商账单为准。消息状态区分“已请求”和“服务端实际回显”；请求成功不等于已经加速。服务拒绝时不自动删参数重发。

## 撤下电脑快速候选选择功能

- 撤下用户电脑、助理电脑设置中的快速模型开关，以及本地 Laya 安装、实际操作测试等入口；agent 不再收到 `fast_pick_action`。
- 原因是当前接法未证明能缩短完整任务时间，且实测出现额外回退和误选。
- 主模型直接使用 CUA、浏览器接口、系统控件、截图和鼠标键盘的能力保留，电脑权限与暂停规则保持。
- 通用分类器服务元数据保留；已有本地模型和用户文件不自动卸载或删除。聊天 Fast 闪电与这个已撤功能不同。

## 原生进程启动修正

- 分离服务的隔离环境与本机浏览器、电脑驱动的启动环境，避免把临时 HOME / 临时目录传播给原生进程。
- 不修改系统钥匙串或权限，不宣称已根治系统授权重授或所有钥匙串弹窗。旧版 macOS 12/13 的 LaunchServices 环境选项未实机验证。

## 验证与限制

最终候选已完成两端类型检查、网页构建、64项服务端定向检查、23项纯逻辑与发布范围检查；聊天 Fast 界面64/64通过，另有真实隔离服务的撤入口回归（两台电脑设置、模型服务、下载登记与旧HTTP接线、聊天Fast/滑块保留）通过，四张关键界面已查看。撤入口测试首次因测试脚本写错设置页键而超时，修正为 `computer` 后通过，非产品修复。

未完成的验证包括真实服务商 Fast 的加速/计费、Codex 登录账号实际 Fast、真机 App 完整操作流程、三平台原生应用与网页全面验收、旧版 macOS 兼容性、全量单测与全量 e2e。构建发布会继续检查各平台打包及 Mac/Windows 安装启动冒烟；这些检查不等于完整任务可靠性验收。

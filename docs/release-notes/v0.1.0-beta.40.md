# Pi Assistant v0.1.0-beta.40

这一版有三处改进，都是为了在聊天里少找、少翻：提示词能一键复制，「等你」的卡片一点就到，往上翻完一点就能回到最新。

- 聊天里的代码块和提示词（深色框）右上角多了「复制」按钮，点一下只复制这一块，按钮会短暂显示「已复制」。单聊、群聊都有，深色、浅色主题和手机上都能用，手机通过局域网打开也能复制。消息下面原来的「复制」「引用」和右键菜单照旧。
- 群顶部的「N 人等你」现在可以点了：点一下就滚到等你审批或回答的那张卡片，并闪一下提醒你。有好几张时，每点一次跳到下一张，从最早的开始。单聊顶部的「等你审批 / 等你回答」也一样可以点。
- 往上翻聊天记录超过大约一屏时，输入框上方正中会出现一个向下箭头的小圆按钮，点一下回到最新消息，回到底部后按钮自动消失。翻上去的时候来了新消息，按钮上会显示有几条。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

本轮只用隔离的临时数据和模拟模型做了自动测试，三处改进都还没在真实使用中看过。

# Pi Assistant v0.1.0-beta.48

这一版主要改群聊和后台干活：群里只用来说话，干活放到后台，做完会自己往下推进；另外 Claude Code 能选具体的模型版本了。

- 群聊不再被一个人占住：
  - 以前一个成员干长活（比如一边装软件一边剪片），整个群都要等它做完，别人插不上话。现在成员一开始动手（做了几步，或者跑满一分钟），就转到后台去做，群里可以接着聊。做完或遇到问题，它再回到群里说。
  - 你没 @ 任何人的话，交给管理者接，不会再塞给正在干活的成员。管理者判断是自己回答、改计划，还是转给负责的人。@ 了谁，照旧直接给谁。
  - 群里只显示说的话：不再刷一条条只有「思考 / 1 个步骤 · 全部成功」的空消息。过程并进这个成员下一条有内容的消息里，点开能看。成员在后台做事时，状态显示「在后台干活」。
  - 成员在群里的对话太长时，空下来就单独整理一次。以前只在项目交付、并且群里没有进行中的项目时才整理，一直有项目的群会越积越长，每想一步都很慢。
- 后台任务并进帮手：
  - 以前「后台任务」做完不会叫醒助理，活常常停在半路。现在助理派活只用「帮手」这一种，帮手做完或失败都会叫醒助理，由它核验结果、接着往下做；失败了先自己换办法。
  - 单聊里每派一个帮手，都会出一张卡片：在做什么、状态、「查看过程」、取消 / 继续。点「查看过程」能看到每一步和正在跑的命令，不再像盲盒。
- Claude Code 能选具体版本：模型列表里除了默认、Opus、Sonnet 这几个，还加上了 Opus 5.5、Sonnet 5.5、Fable 5.1、Opus 4.8、Opus 4.7、Opus 4.6、Sonnet 4.6、Haiku 4.5 等。没有的版本可以在「设置 → 模型服务 → Claude Code → 自定义模型」里填模型 ID 加进去。

这一版测试过的：
- 群聊的改动用测试数据和模拟模型跑过自动测试，没有在真实模型的群里实测。
- Claude Code 的具体版本，在开发测试环境里用测试助理选「Opus 4.8」发过消息，能正常回复。别的版本能不能用，要看你的账号或转发工具支不支持。
- 帮手卡片和「查看过程」用模拟模型在浏览器里看过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

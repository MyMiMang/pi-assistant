# Pi Assistant v0.1.0-beta.44

已于2026-10-29 11:54（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.44)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

这一版主要做两件事：聊天里的文件能直接在 App 里看（网页、Word、Excel、PPT 等），并且像 Claude 一样在聊天右边开一栏显示；另外修了两个容易让人误会的报错提示。

- 文件能直接在 App 里看，不用先下载：
  - 网页（HTML）：像浏览器一样显示，页面里的图表、脚本能正常运行；它放在隔离的环境里，读不到 App 的数据，也碰不到你电脑上的接口。可以切到「源码」看原文。
  - SVG 图：按图片显示，也能切源码。
  - Word（.docx）：按原排版显示，分页、表格、图片、页眉页脚都在。
  - Excel（.xlsx）：表格显示，多个工作表可以切换。
  - PPT（.pptx）：一页一张显示文字、图片、形状和表格；图表暂时显示成占位，要看请下载。
  - Pages / Numbers / Keynote：显示文件自带的预览图（一般只有第一页）。
  - zip 压缩包：列出里面有哪些文件，不解压。
  - Jupyter 笔记本（.ipynb）：按单元格显示代码、说明和输出图片。
  - 文件里的宏一律不会执行，文档里的链接点了会在新窗口打开。老格式（.doc / .xls / .ppt）还不支持，另存为新格式就能看。
- 聊天右边的侧栏：窗口够宽时，点开文件、执行概览、任务、项目、提醒，都在聊天右边出一栏，聊天还能继续看、继续打字。
  - 侧栏可以拖动调宽；点别的文件直接换内容；按 Esc 或点 × 关掉；右上角「放大」用大窗口看。
  - 手机或窗口太窄时，还是原来的弹窗。
  - 改名、新建、删除确认、设置这类要填写的小窗口，还是弹窗。
- 报错提示更准确：
  - 网络断一下、App 自动重试成功时，不再显示红色的「连不上模型服务」，改成一行灰字「网络断了一下，已自动重试」；重试中会显示第几次，真的重试失败了才是红色。
  - 回复已经完整输出后，底下不再多出一条「这次未收到回复」。

经常看到「已自动重试」，一般是模型中转或代理网络不稳，可以检查一下中转服务或换个节点。

这一版用临时数据和真实 Chrome 测过：用 Word / Excel / PPT 生成的真实文件都能打开，网页里的脚本能跑但连不上 App 接口；侧栏在宽窗口、手机宽度、放大都检查过。没有实测的：装好的 App 里的使用、Windows 和 Linux 上的显示，以及暖色 / 像素主题下的侧栏样子。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# 模型选择更集中，任务和定时计划更好查看

- 模型和思考强度合为一个按钮；模型按服务分组，可搜索，常用五个置顶并记住选择习惯。单聊、群聊、子代理共用模型入口，设置中的模型服务可以折叠。
- 助理身份放在最上方，「主会话」紧邻「子代理」。任务概览用短标题、状态、执行者和当前活动展示，进行中的优先，已结束的折叠；点进详情仍可看完整说明、补充要求或停止。顶部不再铺满子代理分页，主聊天里移除大段任务指令卡。
- 待发送图片显示缩略图，可点开大图、移除再发送。工具步骤汇总成功与失败数量，区分某一步失败和任务是否仍在继续。
- 定时任务可以直接选每天的时分、工作日、每周星期或分钟/小时间隔，复杂计划仍可使用高级 cron。旧的特殊 cron 和自定义免打扰时段保存不丢，界面显示中文计划与下次执行时间。间隔继续遵守至少五分钟和均匀执行限制。
- Mac 主窗口使用透明标题栏，给系统交通灯按钮留出位置，改善顶部空间。

本次仅提供 Apple 芯片 Mac（arm64）安装与更新包，Intel Mac、Windows、Linux 暂不构建。保留 beta.18 的完全权限行为：应用层全部免审批。

模型、任务、附件、定时界面已通过 Mock 专项验证，两端类型检查、网页构建及受影响测试通过。Mac 标题栏已通过 Rust 编译和六组布局验证；系统交通灯位置、拖动、双击缩放及全屏进出仍待安装包真机确认。

任务本轮统一展示组件，后台任务、子代理和定时跟进的底层调度仍分别运行。等待期间不常驻调用模型；用量按真实调用记录，不按等待时长估算。

已知限制：缺少 Apple Developer ID 签名证书，更新后系统权限能否保留的问题尚未解决；本版不宣称修复。真实模型与外部渠道账号仍需实际使用验证。

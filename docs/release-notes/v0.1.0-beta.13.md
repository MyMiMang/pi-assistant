## v0.1.0-beta.13

**新功能**
- **后台子代理**：助理可以把耗时的工作交给子代理，主会话继续和你聊天。子代理完成、失败、停止或中断后，主会话会收到回报。
- **子代理聊天分页**：点击子代理图标、选择任务后才打开独立分页，平时不会自动打断主会话。能查看思考、工具步骤和产出，也能直接发消息；完成后还可以接着聊。切换分页保留草稿，关闭分页不停止后台工作。
- **子代理模型设置**：默认跟随主会话，也可以固定模型，或在你勾选的模型里按任务能力自动挑选。
- **用量与费用**：设置里可查看各模型的 token 用量、缓存命中和估算费用，支持自定义价格、折扣和人民币汇率。没有价格的调用显示「—」。
- **组队选模型**：建群时根据成员分工和已配置模型的能力分配模型，可以查看推荐理由并手动调整。
- **工作中随时补充、说停就停**：单聊、群聊和外部聊天渠道支持工作中发消息；整条消息只说「停」会停止正在执行的任务和等待中的审批。

**修复与改进**
- 修复聊天界面缺少思考强度选项的问题，自定义和中转模型的推理能力会自动补充识别。
- 图片模型列表按图片生成能力筛选，避免混入大量语言模型和仅能识图的模型；仍可手动输入模型别名。
- 保留模型在调用工具前单独返回的思考内容，可以展开查看。
- 补充模型价格时只重算对应模型的未知价格用量，保留其他服务及已删除服务的历史记录。

**当前限制**
- 费用取决于服务商返回的用量和已配置价格；国产模型、中转服务的缓存 / 推理 token 与实际账单仍需真实 API Key 对账。
- 标题生成、识图等附带调用尚未计入用量；群聊每条消息的用量展示后续补充。

# Pi Assistant v0.1.0-beta.68

这一版让每条消息都能看到是什么时候发的。

- **每条消息下面显示发送时间**：单聊和群聊里，你发的消息和助理的回复下面，最前面都会显示时间。今天的只显示几点几分（比如 13:36），昨天的显示「昨天 13:36」，更早的带上日期（比如「11月14日 13:36」）。鼠标停在时间上能看到精确到秒的完整时间。以前只有隔了半小时以上才出现一条时间分隔，同一段里的消息看不出各自是几点发的。

这一版测试过的：
- 用测试数据跑过单元测试和单聊、群聊、引用回复相关的浏览器测试，电脑和手机宽度下时间都和「复制」「引用」在同一行，不会挤出屏幕。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

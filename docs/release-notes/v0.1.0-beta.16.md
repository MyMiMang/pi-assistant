## v0.1.0-beta.16

这一版主要重做「完全权限」，并修好权限设置保存与审批误报。其余需求（图片全屏预览、发送快捷键、子代理卡片排版、自定义模型服务增删改）仍在验证中，会在后续版本发布。

**完全权限 = 你电脑上的统一权限**
- 之前「完全权限」有个割裂：桌面能操作，文件读写和命令却还被限制在助理工作区里，超出就要一条条审批。现在完全权限对**文件、命令、桌面**是同一套权限：读写你电脑上的文件、运行命令都不再被工作区拦住，工作区只是默认目录。
- 完全权限下**日常命令自动放行**（npm install、git、ls、which 等不再逐条问你），你可以放心离开电脑让它自己干完活。
- **受保护的操作仍然每次明确批准**，和以前一样：关机 / 重启 / 注销、结束或卸载 Pi Assistant、改系统目录、格式化磁盘、大范围删除、改开机自启和 shell 启动脚本、改网络 / 安全 / 账户设置等。
- 凭据和密钥文件（`.ssh`、`.aws`、`auth.json`、浏览器 Cookies 等）继续直接拒绝，任何档位都不例外。
- 完全权限下助理也能发送你电脑上的文件、查看你电脑上的图片、按绝对路径上传 / 下载浏览器文件。

**修复与改进**
- 修只读命令的审批误报：`ls /usr/bin/xxx 2>/dev/null`、`ls /usr/local/bin > /tmp/x` 这类带无副作用重定向的只读命令，不再被当成「修改系统目录」而弹审批。
- 电脑设置的改动现在会真正保存并给你反馈：关闭状态下改选项会自动保存（显示「已自动保存」）；开启状态下改动会提示「有未保存的更改」，需要重新查看权限清单并确认后才生效，不会再出现「改了没保存、重开又变回去」。
- 切换某个助理的权限档位时，显示「正在保存 / 已保存」，失败会给出原因。
- 修权限卡片文字叠加、越框的问题，窄窗口和手机上正常换行显示。
- 降低权限、从允许名单移除、关闭开关或一键暂停时，正在运行的主机命令、子代理和后台任务会**立即中止**，不用等这一轮跑完。
- 权限判断集中在一处（`hostFileAccess`），各工具统一调用；完全权限即使沙箱偏好是 Docker，命令也在你电脑上跑（普通档位仍然进容器）。

**当前限制**
- 安装包仍未签名：macOS 首次打开要右键 → 打开，Windows 会有 SmartScreen 提示（选「仍要运行」）。
- 完全权限下助理是以你本人的身份运行命令，请只在信任的助理上开启；受保护清单之外的操作不会逐条问你。
- 后台子代理的运行时长判断（有进展不应只因固定时长被认定卡住）还没做，仍在设计中。

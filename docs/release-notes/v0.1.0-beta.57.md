# Pi Assistant v0.1.0-beta.57

这一版整理了 设置 › 模型服务 里编程工具的布局。

- **编程工具收起来了**：Claude Code、Codex、Gemini CLI、CodeBuddy 等编程工具，现在收在一个「编程工具」分组里，默认折叠，标题旁显示有几个。点开后在框里滚动，不会把下面的模型服务挤到很远。
- **按钮放到顺手的位置**：每个工具的「安装」「登录」「更新」按钮现在都在「重新检测」旁边。状态（正在安装、正在登录、有新版本）显示在状态那一行。
- **去掉重复提示**：没装的工具不再在下面重复写一行「尚未安装」。

这一版测试过的：
- 用测试数据和假的工具程序，跑过单元测试和 5 个编程工具页面的浏览器测试：Claude Code、Codex、Antigravity、OpenCode，以及 Gemini CLI / CodeBuddy 的安装、登录、更新。
- 还没有真实安装和登录过 Gemini CLI / CodeBuddy，也没有在你装好的 App 里测试过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

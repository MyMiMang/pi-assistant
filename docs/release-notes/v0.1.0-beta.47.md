# Pi Assistant v0.1.0-beta.47

已于2026-11-03 14:57（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.47)。五个平台构建、Mac/Windows安装启动检查均通过，13项资产已上传；可在已安装App中检查更新。

这一版专门给「操作这台电脑」提速。以前助理每做一步都要截一张图、再把之前所有截图重新看一遍，步与步之间常常要等半分钟到一分半；现在先读网页和窗口的结构、按编号操作，基本不用截图。

- 操作电脑快多了：
  - 发给模型的内容里只留最近几张截图，不再每一步都重读几十张旧屏幕。上下文小了，每步等待和费用都明显下降。
  - 读窗口默认不截图，先读结构；只有读不出结构、或者要看画面效果时才截图。
  - 网页上传文件直接填路径一步完成，不再去点系统的文件选择窗口。
  - 几个已经想好的动作可以一次做完，只在关键节点核对，不再每步核对。
  - 浏览器连不上时按官方的办法恢复，不再退回「全屏截图 + 快捷键」的慢路线。
- 操作电脑的组件 Cua Driver 升到 0.38.0：批量动作和读窗口更快，动作被拒时会给出怎么恢复的提示，新增网页下拉框选择，助理不确定时可以自己查官方使用说明。第一次使用新版本会重新下载一次（约 29MB）。
- 修了助理「看不到」网页编号的问题：以前网页的标签页编号、按钮和输入框编号没有交给助理，它读不了页面，只能反复试；现在都会交给它。
- 更安全：
  - 助理不能再用命令或脚本绕开权限，直接去调操作电脑的组件。
  - 一次做多步时，里面混了认不出的动作会整批拦下。
  - 这两条所有权限档位都生效。

这一版在隔离的开发测试环境里，用测试助理在你的电脑上实测过：打开一个本地测试网页，填名称、选下拉、上传 3 张图片、提交。修改前用了 482 秒、约 45 步，中途还绕路；修改后 121 秒、14 步，没有截图。

没有实测的：
- 助理电脑（虚拟机）里的操作组件还是 0.35.4，这次没升级；上面「只留最近几张截图」和「操作说明」对它也生效。
- Windows 和 Linux 上的操作电脑。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

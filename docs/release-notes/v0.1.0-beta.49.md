# Pi Assistant v0.1.0-beta.49

这一版把帮手的入口统一了：在哪里看到帮手，都能点进去看它在做什么。

- 左侧栏原来的「后台任务 · N 个任务进行中」只是一行字，点不进去。现在改成「帮手 · 某某 N 个在干活」，点一下打开这个助理的执行记录。
- 信息面板「任务 → 执行记录」原来是只读列表，而且新派的帮手不在里面。现在所有帮手都列出来（主动巡检除外），每一行都能点开，看每一步在做什么、正在跑的命令、最后一次活动的时间。
- 聊天里的帮手卡片、顶部的「执行」按钮、侧栏、执行记录，打开的都是同一个帮手详情页。

这一版用模拟模型在浏览器里点过侧栏入口和执行记录，助理详情相关的自动测试也都通过了。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

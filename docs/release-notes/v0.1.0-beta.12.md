## v0.1.0-beta.12

**新功能**
- **工作中随时发消息**：助理正在干活时，你可以直接发新消息，不用等它做完。它做完当前这一步就会读到你的话，然后按新的要求调整。消息下方会显示「已送达正在进行的任务」。单聊、群聊和微信、飞书等渠道都可以这样用
- **说停就停**：助理工作时，整条消息只发「停」「停止」「别做了」，它就会马上停下，正在跑的命令、电脑操作和还没处理的审批都一起取消。群聊里说「停」，全群一起停

**修复与改进**
- 和 beta.11 一样包含 Windows 修复：打开后不会再显示「拒绝连接」，启动中先显示「正在启动…」，启动失败时可以重试或复制诊断信息
- 发版前会先在干净的 Windows 和 Mac 上真的安装、打开一遍，确认能用才推送自动更新

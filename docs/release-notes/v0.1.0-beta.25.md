# v0.1.0-beta.25：Enter 默认发送、设置按功能重排、语音来源显式选择、Pi 1.3.0 与一批修复

> 状态：**已公开发布 v0.1.0-beta.25（Latest，仅 Apple 芯片 Mac / arm64）**。[CI 38857423620](https://github.com/MyMiMang/pi-assistant/actions/runs/38857423620) 构建、内置服务冒烟、Mac 安装启动冒烟和发布全部通过；公开自动更新版本 / arm64 平台 / 签名已核验。应用尚无 Apple Developer ID 签名，更新后可能需要重新授予系统访问权限；更新包签名不等于 Apple 签名。

## 先说最需要知道的：发送键默认改回 Enter

- 现在默认 **Enter 发送、Shift+Enter 换行**（上一版是 Shift+Enter 发送）。
- 改回 Enter 是因为**中文输入法用回车确认候选字时会被当成发送**，造成误发。这次把输入法组字判断修好了：组字中（含 `keyCode 229`）的回车交给浏览器原生处理，不会发出去。
- 想换回去：**设置 › 聊天与输入** → 「Enter 发送 / Shift+Enter 发送」二选一。按**设备**保存，刷新仍生效；同一服务上的其它设备不受影响。
- 如实说明：这是按输入法**事件序列**（真实浏览器 + 合成组合）自动测试的，**不是在真实 macOS 输入法上人工验证**，不能保证所有输入法 / 系统组合都与测试一致。

## 设置按功能重新整理

- 原来的 15 个标签平铺，现在分 **5 组、共 17 项**：
  - **模型与语音**：模型服务、语音配置（新）
  - **电脑**：助理电脑、操作这台电脑
  - **助理能力**：记忆、技能库、扩展（MCP）
  - **连接**：渠道、邮箱、远程访问与设备、固定地址 / 入口
  - **偏好与系统**：聊天与输入（新）、外观、桌宠、用量、下载与组件、关于与更新
- 只换位置和文案，**不删功能、不重置配置**：模型服务地址 / Key、已声明的语音模型、每个助理的模型与思考强度、记忆后端、权限档位、技能启用、定时任务、主题——全部原样保留，**不用重填**。
- 模型服务页只放**在线模型服务**（地址 + Key + 能力声明）；本地 Laya 移到「操作这台电脑」；本地语音移到新的「语音配置」页；子代理的并发 / 最长运行移到**每个助理**的设置里（不新增入口）。
- 长说明收进「?」帮助（鼠标悬停、点击、触摸、键盘 Tab、Esc 都能开 / 关）；主界面只留功能名 + 状态 + 主操作 + 真实错误。

## 语音：来源必须你显式选择

- 新增「语音配置」页，云端 / 本地由你切换，**不会自己换成云端、不会静默计费**。
- 没选 = **未配置**：点麦克风会提示你去语音配置，不会自动挑一个云模型花钱。
- 云端只使用你在「模型服务」里**已声明的语音识别模型**，不用重复填地址 / Key。
- 本地语音识别（SenseVoice）：模型权重**许可仍未解决**，因此**默认不提供下载**；只支持导入你自行合法取得的权重（导入时按固定清单 + 校验和检查）。

## 快速操作模型：配好 Jev 就自动识别

- 在「模型服务」里配好 Jev 后，它会**自动出现在**「电脑 › 快速操作模型」下拉里，不用再手动声明分类器。
- 只按**可靠来源**识别（对端接口明确声明、模型 id 与 Pi 官方目录一致、或你显式标的能力），**不靠名字里带「Jev」猜**；协议无法确定就**不注册**，不会向未知端点乱发请求。
- 复用同一份地址 / 凭据，**不用重复填第二个 Key**。
- 本地 Laya 一键安装仍在「操作这台电脑」：主卡片只留**状态 + 安装 / 启停**，其它细节收进「详情」。**Laya 是快速操作分类模型，不是语音识别**——请不要去语音配置页找它。

## 模型「常用」修好了

- 常用只是菜单顶部的**快捷入口**，**不再把模型从原渠道分组里搬走**（上一版：某个渠道只有一个模型时，选过之后整组会消失）。原渠道分组照常保留，跨渠道同名模型各自保留。

## 底层：Pi SDK 1.3.0

- 只升官方发布包，**精确固定 1.3.0**，没有改 Pi 本体、没有 fork、没有改 `node_modules`、没有用私有接口。
- 会话里激活过的工具在重启后能保留（Pi 1.3 的新特性）；已移除 / 隐藏 / 被限制名单排除的工具不会因此复活。
- 顺手修了保存自定义服务偶发报「Unknown provider」（有界重试一次，不掩盖真正的身份 / 凭据错误，也不重复付费探测）。

## 修复

- 设置三页（操作这台电脑 / 助理电脑 / 渠道）**加载慢或失败时不再整页空白**，会显示中文原因和重试。
- 助理自己的电脑审批移到「助理电脑」页（不再和操作用户电脑混在一页）。
- 语音入口：未配置时的「去设置」**不再常驻**，只有你点了麦克风且没配好才短暂出现。
- 共享下拉菜单**滚动时误关闭**（真实 bug）；下载来源的技术输入折叠起来。
- 测试隔离加固：新 e2e 不再继承真实工作区、不构造系统钥匙串后端（改用内存凭据），并断言钥匙串调用为 0。

## 已知问题 / 未验证（如实）

- **未验证**：真实云端语音识别与本地 SenseVoice 的真实安装 / 转写；真实 Jev 调用（不声称真实速度、准确率）；本地模型权重下载与安装（许可未解决，默认下载关闭）；真机安装包 / iPhone / iOS；**真 Safari 与真实系统输入法**（发送键只到事件序列级，不是真机人工验证）。
- 本轮**全量测试不是全绿**：`e2e/run.mjs` 第 1 步「首次运行向导」仍在等一个旧按钮（`main` 上同样失败，属既有基线，与本次无关）；全量 `npm test` 也有既有基线失败（如 `shared-computer` 的 macOS bsdtar 参数）。本次只跑受影响项与专项用例，未重跑全量。
- **系统钥匙串弹窗的根因仍未查明**，不能承诺修好；本次没有重置钥匙串、没有清空用户数据。测试隔离加固只是把新 e2e 从真实钥匙串 / 工作区分开，不代表系统钥匙串问题已解决。
- SenseVoice 许可仍未解决，**默认不下载**，只支持导入合法权重。
- 未做 Apple 代码签名 / 公证：每次更新后 macOS 会再问一次系统文件夹权限（历史问题，与本次改动无关）。

本次仅提供 Apple 芯片 Mac（arm64）安装与自动更新包；Intel Mac、Windows、Linux 本轮不构建。

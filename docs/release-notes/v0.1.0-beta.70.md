# Pi Assistant v0.1.0-beta.70

这一版加了「让助理自己整理人设」，并修了 Codex 一开对话就报错、下拉框模型名显示不全两个问题。

- **助理可以自己整理人设了**：在助理详情 › 资料里，「人设」旁边多了一个「让它整理」按钮。点一下，助理会读你们最近的单聊（不读群聊），把你反复提到或纠正过的做事要求整理进人设，并列出「改了什么」。它不会直接改：你点「采用」后新内容只是填进输入框，还能再改，点「保存资料」才真正生效。用的是这个助理自己选的模型，只在你点按钮时才整理，不会在后台自己跑。
- **修好 Codex 一开对话就报错**：用 Codex 模型的助理发消息时报「dynamic tool name is reserved: mcp__hostpc__…」。原因是新版 Codex 不允许工具名以 `mcp__` 开头，而「操作这台电脑」的工具正好是这个名字。现在传给 Codex 时会自动改名，调用回来再换回原名。
- **下拉框能显示完整名字了**：比如 设置 › 模型服务 里的「默认图片模型」，名字长了以前会被截成「…」。现在下拉列表会按名字长度自动变宽，也不会超出屏幕。

这一版测试过的：
- 用测试数据和测试模型跑过单元测试和浏览器测试：整理人设（采用、放弃、没有变化、出错重试、切换助理）、Codex 渠道、下拉框在电脑和手机宽度下的显示。
- 用你电脑上的 Codex 程序在隔离目录里确认了它拒绝哪些工具名；但没用你登录的 Codex 真实跑一轮对话。
- 整理人设只用测试模型试过，没用真实模型看过实际整理效果。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# Pi Assistant v0.1.0-beta.51

这一版主要改「操作这台电脑」：开起来更简单，用起来少等几轮；单聊里的过程也不再一步一块地刷屏。（没有 beta.50：那一版打包到一半取消了。）

- 给助理设权限就能用了：
  - 以前给助理选了「完全权限」、也确认了风险，还要另外去 设置 › 操作这台电脑 再看一遍权限清单、勾同意、点「确认开启」，不然显示「未开启」。现在在助理的「权限」按钮（或 助理详情 › 电脑）里选一个档位、确认一次，就直接开启。
  - 从没开过的状态开启时，只开你点的这一个助理，别的助理不会跟着打开。
  - 「限定」档的助理还没选应用时，不再让设置页的开启按钮变灰点不了；它只是暂时不能操作，界面上会写明，助理也会告诉你要去选应用。
  - 风险确认还在：调高档位照旧要确认，「完全权限」照旧是红色的「确定启用」。
- 快速执行（可选，默认关）：
  - 在 设置 › 操作这台电脑 › 快速执行 打开，并选一个决策模型（比如 TypeSafe 的 Jev，用 TypeSafe 或 OpenRouter 的 key 都可以；OpenRouter 要用普通 API key，不能用管理用的 key）。大模型把要做的几步一次写好，比如填表、选下拉、勾选、上传、点按钮，每一步从页面或窗口里真实存在的元素里挑一个来执行，不用每一步都等大模型想。
  - 新增「快速打开」：一次把网页或应用打开、连好、读出内容，还可以顺带把要做的几步一起做完。用你自己的 Chrome 时，只用空白标签页，不会把你正在看的页面换掉。
  - 读得到计算器显示屏、状态文字这类「不是按钮」的内容；做完会直接写明页面上新出现或变了什么，助理不用再截图核对。
  - 每个动作照常按你给的权限档位审批；页面还在加载时会等一下再看；拿不准或被拒绝时会停下交回助理，不会自己换方式乱试。
- 单聊不再刷屏：只有「思考」没有文字的一步不再单独占一块，前后步骤连成一组；帮手详情里照旧能看完整过程。
- 底层的 Pi 升级到 1.5.0。

这一版测试过的：
- 开启流程：用测试数据和模拟模型在浏览器里点过「权限」按钮开启、设置页开启；在开发测试环境里用测试助理实际开启过。
- 快速执行：在开发测试环境里，用测试助理（gpt-6.1-sol）在你的电脑上跑了三个任务。用计算器算乘法从 246.5 秒降到 54.4 秒；本地测试表单（填写、选择、勾选、上传 3 张图、提交）从 81.7 秒降到 75.1 秒；测试商店里「搜索 → 点开 → 读价格」交给目标模式一次做完，从 125.7 秒降到 62.5 秒。
- 没有在你装好的 App 里、用你自己的助理测试过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

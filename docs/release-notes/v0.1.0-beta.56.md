# Pi Assistant v0.1.0-beta.56

这一版主要新增：Gemini CLI 和 CodeBuddy 可以直接当助理的模型用，并且按它们自己原本的方式干活。

- **一键安装、点击登录**：在 设置 › 模型服务 里，Gemini CLI 和 CodeBuddy 各有一张卡片。没装的点「安装」，装好点「登录」，会打开浏览器走它们的官方登录；登录后就能在模型列表里选它们。
- **和你电脑上的完全分开**：不管你电脑上有没有装这两个工具，Pi 都单独装一份自己用。设置、登录、规则文件、历史都和你自己的那份分开，不会改你电脑上的任何配置。
- **按它自己的方式干活**：选了它当模型后，它用自己的读写文件和执行命令能力，在助理的工作文件夹里干活。同时也能用 Pi 的工具，比如助理电脑、浏览器、记忆、群聊、发文件。
- **批准照你的权限档位来**：它发来的批准请求会在聊天里弹出批准卡片；助理开了完全权限的就直接放行。凭据文件一律拒绝。暂停「操作电脑」时一律拒绝。它做的每一步都会显示在聊天的过程步骤里。
- **版本你说了算**：卡片上显示当前版本。点「检查更新」才去查新版，点「更新」才会装，不会自动更新。
- **安装组件更稳**：下载组件时遇到服务器临时出错会自动重试。
- **上游组件升级**：高级记忆（Hindsight）升到 1.2.0，记忆存取更可靠。助理电脑用的 lima 升到 2.3.0，修了虚拟机能读到宿主文件等安全问题。另外 cloudflared、nerdctl、uv、Node 也升了小版本。

需要注意：
- 有些读文件的操作，工具不会逐个请求批准。
- Mac 上，工具存在系统钥匙串里的登录可能和你自己那份共用。
- 它正在做事时你插的话，会在这一轮做完后送到。

这一版测试过的：
- 用测试数据、模拟模型和假的工具程序，跑过单元测试和浏览器测试。覆盖安装、取消、登录、更新提示、选为模型、过程步骤、批准卡片，以及批准后写入文件。
- 原有的 Claude Code、Codex 模型服务页面也重新测过。
- Hindsight 1.2 用模拟模型做过冒烟测试。
- 还没有真实安装和登录过 Gemini CLI / CodeBuddy，也没有用真实模型跑过它们干活。也没有在你装好的 App 里、用你自己的助理测试过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

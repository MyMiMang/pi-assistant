# Pi Assistant v0.1.0-beta.63

这一版改了编程工具「额度用完」时的处理。

- **额度用完会马上告诉你**：以前用 Antigravity 等编程工具当模型时，如果服务方回复「额度用完了」，Pi 会自己重试好几轮，每轮要等一两分钟，你可能十多分钟都看不到任何回复。现在会马上停下，用中文提示「额度用完了，可以换个模型，或等额度恢复后再试」，后面附上原始报错。
- 其他错误（比如网络临时断开）还是照旧自动重试。

这一版测试过的：
- 用测试数据跑过单元测试，以及 Antigravity 和其他编程工具的浏览器测试。
- 还没有在你装好的 App 里遇到真实的额度用完时看过效果。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

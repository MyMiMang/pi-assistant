# 修复微信渠道凭据异常导致应用无法启动

- 修复 beta.22 在读取渠道凭据失败时，整个后台退出、应用停在启动报错页的问题。现在只显示对应渠道的错误，其他功能可以继续启动。
- 设置里的渠道列表可以正常打开，并提示重新连接。微信旧凭据无法读取时，也能重新扫码；扫码取消会保留旧凭据，确认成功后才保存新的凭据。
- 停用或修改渠道名称会保留原凭据；其他渠道需要重新填写密钥时，只在完整填写后替换。

验证：16 项渠道相关测试、服务端和网页类型检查通过。真实微信重连仍需更新后验证；本次未确定原凭据解密失败的根源，也没有清空用户数据或重置系统钥匙串。

本次仅提供 Apple 芯片 Mac（arm64）安装与自动更新包。

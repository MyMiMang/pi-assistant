# v0.1.0-beta.29

状态：**候选（未打包 / 未 push / 未 tag）**。本版继续保留 beta.28 的全部内容（手机聊天首屏更快、语音分段出字与真实音量、表格不被裁、子代理入口、UI 一致性与动效），并新增**默认本地语音（开箱即用）**与电脑授权相关的修复。

## 思考强度：七档离散滑块

- 输入栏、群聊成员、子代理、以及「设置 › 模型服务 › 新助理默认模型」里，原来的档位下拉换成**同一块离散滑块**：拖动、点击刻度、方向键 / Home / End / PageUp / PageDown 都能选，`role="slider"` + 中文 `aria-valuetext`，手机 44px 命中。
- 档位仍然是 Pi 的七档（关闭 / 极简 / 低 / 中 / 高 / 超高 / 最大），**一格一个真实档位**，没有「63%」这种模型不存在的值；每个模型只显示它自己支持的档位，多候选池取**并集**（不取交集，不会把 xhigh / 最大悄悄裁掉）。
- 拖动过程中只预览，**松手才保存**；窗口失焦、`pointercancel`、Esc 关闭都不提交半途预览。点当前已生效的那一档不会重复写库、弹层也不关（避免无意义写入）。
- 保存失败时界面**不留下假值**：回落到服务端确认过的档位再回读一次真值；连续快速切换时，**前一次请求的迟到失败不会覆盖你后选的那一档**。
- 档位语义不变：`关闭` 是模型的一档（不是 0%）；子代理的「跟随助理默认 / 跟随主会话」仍是滑块外的 reset 动作，不是第 8 档；服务端收敛规则未改。

## 主题：AI DIY 动效参数 + 可以看见的动效

- DIY 主题（AI 造主题）新增可选的**动效参数**：时长、缓动、倍率、光晕、风格（`smooth` / `steps`），面板里多了「动效微调（可选）」；AI 没给或给得不完整时补内置默认，**旧主题（没有动效段）仍然合法**。
- 滑块、按钮、下拉等公共控件真的吃这套参数：切主题立刻生效（包括 `steps` 这种离散风格与 ×倍率后的动画时长），**不需要重开界面**；系统「减弱动效」时一律置零并停掉循环动画，主题无法绕过。
- 修了两处真实问题：① 编辑已有 DIY 主题后再「取消」，原主题不再从运行中消失（预览取消不会误删已保存主题的注册）；② AI 给出枚举之外的合法值（例如自定义 `cubic-bezier(...)`）时，「动效微调」下拉会**原样列出**这个值，不再显示成「默认」、也不会被顺手改掉。


## 默认本地语音：装好就能用（本地原生流式听写）

- 全新安装、**从没设置过**语音来源时，会在后台**自动准备**一个本地中英双语流式模型，准备完成后自动成为当前语音来源；你不用自己找模型、点下载或填路径，也不用提供任何云 key。
- **首次需要联网**（下载权重约 198 MB + 共享运行环境，界面会写清「首次需联网自动准备，之后可离线使用」）；它**不随安装包分发**，也不会伪装成「首次断网就能用」。
- 说话时**边说边出字**：已确认的文字直接进输入框，没确认的尾巴只在录音状态行预览，不会写进草稿、也不会自动发送；点停止后把最后一句补全。
- 你可以随时在 设置 › 语音配置 里取消自动准备、失败后重试；取消或清空来源后**不会自己又装一遍 / 又改回来**，选别的模型也不会被默认覆盖。手机连上来同样可以取消 / 重试。
- 这个默认模型**输出没有标点**（不加付费云补标点）；设置里原有的 SenseVoice / Paraformer / Whisper 与云端选择都还在，可以随时换。
- 本轮在真机上用官方两个 wav 做过真实流式验收（分帧喂音频、不用等 stop 就能拿到非空的临时结果、断网拦截下复用已下载的权重仍能识别）。需要说清的：这两个样例一个中英混说、一个中文夹英文，**都不是纯英语语料**；对照的也只是**官方文档里模型的示例输出（不是人工转写真值）**，所以只能算「跑通并复现官方示例」，**不能当准确率或中英文质量结论**。**不承诺**通用语料质量，也未在 Windows / Linux / Intel Mac / 真手机上验证过。

## 电脑授权：更新后不再像「权限被重置」

- 修了「更新 App 后看起来像所有电脑操作权限都没了」的问题：电脑操作工具现在**按你的实际授权**挂载，启动时不再因为某个工具初始化失败就整体不可用；启动失败会做**有限次重试**，失败信息也会如实说明原因，不把「还没来得及授权」说成「你操作错了」。
- **如实说明**：这台机器上的 App 目前是 ad-hoc 签名（没有稳定的 Developer ID 身份），macOS 的「辅助功能 / 屏幕录制」授权是**按签名身份**记的——所以系统本次仍可能要求你重新授权，**本版代码不能保证以后每次更新都不再询问**。要彻底避免重复授权，需要用正式 Developer ID 证书稳定签名（这是你的安全配置，不是代码能替代的）。
- 「完全权限」仍是应用层免审批（凭据文件、暂停、系统权限弹窗照旧），没有绕过 macOS 的系统授权。

# v0.1.0-beta.27：修复 Laya 安装启动、开放 SenseVoice 一键安装、修复权限按钮遮挡

状态：已于 2026-10-16 20:48（Asia/Shanghai）公开为 Latest。Apple 芯片 Mac（arm64）构建、Mac 安装启动冒烟和发布全部通过，公开更新清单版本、平台和非空签名已独立核验。

## Laya 安装与启动

- 修复缓存中两层符号链接被误判为越界的问题，支持普通文件、单层与共享 blob 两层布局；仍校验文件大小、SHA256 和缓存边界。
- 保留已有缓存，可直接重试安装，无需先删除缓存。断链或缺文件与真正越界分别提示。
- 修复安装环境改名后启动路径失效、冷加载等待过短，以及进程启动失败和首次写日志可能导致服务异常的问题。
- 已在独立 Apple 芯片环境完成真实权重下载、校验、安装、模型启动和一次分类调用，并验证测试进程退出。一次分类仅证明调用链路可用，不代表电脑操作准确率评测。

## SenseVoice 一键下载使用

- SenseVoice 保留在原模型列表，支持“安装并使用”，接入统一下载进度、取消、失败重试和来源选择。
- 无需手动寻找权重；已有权重导入功能仍在详情中保留。
- 修正应用将许可解释待确认直接等同于禁止下载安装的策略。保留 FunASR 模型许可、署名及用途说明，不将权重标成 Apache，不宣称所有商业用途已获最终确认；权重按需下载，不随安装包分发。
- 已真实下载并校验约 240MB 权重，启动 SenseVoice 并完成官方中文样例转写。样例“开放”识别为“开饭”，不声称零误差。

## 权限按钮不再遮挡内容

“操作这台电脑”中的“查看权限清单”操作条恢复正常随页面滚动，不再吸底覆盖内容。权限查看、保存和确认功能保留；桌面和 390px 窄屏滚动及确认流程已验证。

## 验证范围

主会话在最终整合版本通过两端类型检查、网页构建、87 项关键服务端测试、6 项前端逻辑测试，以及语音模型和设置页面交互测试。Laya、SenseVoice 的真实运行在隔离环境验证，未修改用户缓存或自动安装用户 App。

本轮未做 Windows、Linux、Intel Mac 实机验证，未验证真实麦克风的完整录音流程，也未做 Laya 的电脑操作准确率评测。CI 构建与 Mac 安装启动冒烟已通过，未在用户电脑自动安装更新。

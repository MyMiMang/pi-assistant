# 断点续跑更安全，助理电脑能自己配资源

- 子代理断网或服务重启后继续任务时，只在确认没有「已派发但结果未知」的动作时才自动继续；如果有些工具调用结果没落库（可能已经发送、写入或提交），会把工具名列出来，请你先核实再决定，不会直接重跑、不重复副作用。读不到会话文件时一律按不安全处理，不从头重来。
- 助理电脑可以在设置里自己配 CPU、内存和磁盘：改完关机后生效；磁盘只能扩大、不能缩小（缩小会丢数据，界面会直接说明）。空闲自动关机时间也改成应用内下拉。
- 模型设置：内置服务显示真实品牌图标；「模型服务 / 渠道」收成一个大分类，可以一键全部关上；修好了模型选择菜单在设置弹窗里跑偏、以及设置 › 模型 › 子代理两个数字输入框显示空白。
- 每个子代理可以单独设置思考强度（跟随助理默认，或跟随主会话）。
- 新增「快速操作模型」（默认关闭）：开启后主模型仍负责规划、授权和异常判断，快速模型只在程序给出的有限候选里挑一个控件；可以选原生 Jev（System One）分类器，也可以用 OpenAI 兼容的快模型替代（替代模型没有原生概率，一律要求独立核验）。关闭时完全沿用主模型、零额外调用。
- 子代理完成的通知和任务等待不再重复唤醒（同一件事只唤醒一次）；主动能力改为有变化才行动，并能在相关对话里继续推进。
- 助理电脑镜像升级到 CUA 0.35.4：批量动作按每一步单独做权限检查，不提供脚本执行。

本次仅提供 Apple 芯片 Mac（arm64）安装与更新包，Intel Mac、Windows、Linux 暂不构建。保留 beta.18 的完全权限行为：应用层全部免审批。

以上改动在本地用 Mock 模型和模拟环境验证：两端类型检查、网页构建通过；断点续跑、子代理、任务等待、思考强度、分类器持久化、快速操作模型、助理电脑资源等定向单测通过（续跑 / 子代理 / 等待 / 档位 / 分类器 91/91；分类器 / 快速操作 / 助理电脑 81 项，80 通过、1 跳过、0 失败）；e2e（model-ui / subagents / task-ui / settings-subagent / settings-desktop-resources 等）通过。助理电脑镜像 digest 与 CUA 0.35.4 资产哈希已与 GHCR / 官方发布交叉核对一致。全程不调用真实模型、不使用真实密钥。

已知限制：缺少 Apple Developer ID 签名证书，更新后系统权限能否保留尚未解决；本版不宣称修复。断点续跑**不承诺副作用恰好一次**：结果未知时只保证「不自动重跑」，最终仍需核实实际结果。快速操作模型默认关闭，原生 Jev 未用真实密钥调用验证，性能未实测。助理电脑资源调整、安装包真机、真实模型与外部渠道账号仍需实际使用验证。

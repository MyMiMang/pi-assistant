# v0.1.0-beta.72

聊天右侧现在是共用工作区。文件、任务、项目、提醒、模型设置和助理正在使用的网页可以在标签间切换；收起、放大和返回聊天会保留内容。窗口较窄时切换到单内容页，也能返回聊天继续交流。工作区沿用现有主题与 DIY 外观。

网页查看使用助理浏览器里原来的页面，支持连续画面、选择页面、地址栏、前后退和刷新。需要亲自操作时可以接管，交还后助理再继续；接管等待超时会保持锁定并提供恢复入口。断线、收起或关闭查看不会自动交还控制权，也不会关闭网页。多个查看窗口之间的旧控制请求会被拒绝，防止误交还当前控制权。

模型设置可以在工作区里查看，和助理详情共用原来的模型、思考强度和 Fast 设置。自定义模型的推理能力现在明确区分「未识别」「支持」「不支持」，可以按渠道文档声明可用档位及协议值，也可以恢复自动识别；保存后的档位供各处共用选择器使用。

验证范围：本机 Mac、全新临时 Chrome 配置、本地网站和 Mock 模型；已核验工作区主题/窄屏、同一真实网页的工具与界面操作、接管交还、断线保状态，以及实际发送到本地 Mock 的推理参数。发布安装包由既有全平台流程分别构建并冒烟检查，结果以本版本的发布运行记录为准。

限制：真实 sandbox/VM、Windows/Linux 上的工作区交互、Tauri、真手机/PWA 远程及弱网尚未实测。网页画面不含音频，窄屏采用整幅缩放；中文通过独立输入框输入，原生输入法候选、拖拽触控和网页原生文件选择器未验证。运行环境在任务中固定，不支持 host/sandbox 无损迁移或服务重启后恢复网页状态。生产中转对 6.2-astra/sol 的具体推理档位与 max 支持未验证，本版不会自动改写这些模型的生产配置。

本次也包含 beta.71 后主线已验收的测试断言与公开快照误报收尾。不修改发布门禁或依赖版本。不会自动安装或重启当前应用。

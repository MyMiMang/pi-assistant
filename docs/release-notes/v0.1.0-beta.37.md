# Pi Assistant v0.1.0-beta.37

已于2026-10-22 22:14（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.37)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

- 群聊改成像一个「AI 团队」那样干活：
  - 去掉了「自主推进」开关。你在群里说要做一件事，管理者会先想清楚，必要时只问你一两个关键问题，然后发一张**方案卡**：要做成什么、怎样算完成、谁负责哪块、分几个阶段、哪几个节点要请你看一眼。你点「就这么干」或在群里说「可以」，团队才开工；点「先不做」就不做。
  - 开工后任务按阶段自动接力：前一步验收通过，下一步自动开始，并带上交接说明和文件。成员干到一半可以直接问同事，问答在群里都看得到；一个问题来回几轮没解决，会交给管理者处理。
  - 每完成一个阶段，管理者会简短告诉你做到哪了。到了方案里写的关键节点，会出一张卡片请你看一眼，你答复之前后面受影响的活先不做。全部做完会发一张**交付卡**，写清做成了什么，附上能直接打开预览的文件、怎么用，以及还没做的部分。
  - 群顶部的「项目」入口可以看方案和每个阶段的进度，也可以随时停下项目，或接着做停下的项目。同时有两个以上项目在做时，可以按项目筛选群消息。
  - 以前开着「自主推进」的群，会自动变成一个进行中的项目，不用重新设置。
- 单聊里交给助理一件需要好几步的大事时，它也会先出方案卡，你确认后再按阶段推进、最后交付。闲聊和小事照常直接做。
- 新建助理多了一个「全能培训师」模板：选它会自动填好人设，并启用「组建团队与入职强化」技能。可以用它按目标帮你组建群聊团队，或者给新助理做一次入职培训。
- 单聊输入栏的「技能」按钮换成了「权限」按钮：按钮上直接显示这个助理操作你电脑的档位，点开就能切换（只看 / 限定 / 信任 / 完全权限），调高仍要你确认。助理已经启用的技能照样会在需要时自己用。
- Windows / Linux：滚动条改成跟主题一致的细滚动条，窗口标题栏跟着 App 的深色 / 浅色切换，深色主题下不再顶着一条白边。
- 手机上，群聊顶部按钮一多会被挤出屏幕，现在能左右滑动看到全部按钮。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

本轮验证用的是隔离的临时数据、模拟模型和浏览器自动操作。真实模型下管理者的方案质量、团队按方案推进得怎么样，Windows 上的滚动条和标题栏效果，都还需要你实际用一下确认。

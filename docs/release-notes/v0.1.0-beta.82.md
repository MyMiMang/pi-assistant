# v0.1.0-beta.82

在「设置 › 模型服务 › 编程工具 › Antigravity」新增 RT 多账号登录与手动切换，并保留原来的 Google 账号登录。

- **多账号导入与切换**：支持粘贴多个刷新令牌（RT）导入账号并加密保存在 Pi 内；添加不会自动替换当前账号，可在「管理账号」里随时切换或移除未使用的账号，也可以随时切回原来的 Google 登录。
- **独立环境不串号**：每个 RT 账号使用 Pi 自己的独立目录和登录文件，通过受管反重力命令行直接验证和刷新，不读取或修改你电脑上单独打开的反重力账号，也不影响 Pi 原本的聊天调用方式。
- **失败保旧**：验证失败、取消或当前有任务在跑时不会覆盖正在使用的账号。

# Pi Assistant v0.1.0-beta.39

这一版有三处改进：一眼看出群里谁在干活；群里做了好几个项目以后回复不再越来越慢；消息可以一键复制。

- 群聊和单聊里能看到每个助理的工作状态：
  - 群顶部的成员条里，每个助理头像旁有个小圆点：绿色是工作中，黄色是在等你，灰色是空闲。名字下面一行写着它在做什么，比如「在群里回复」「做任务「…」」「等你审批」「空闲」。
  - 成员条最左边是整个群的状态：「2 人在干活」「1 人等你」。大家都停下时会写「都停下了」，免得事情做完了你还在等。
  - 单聊顶部也会显示助理是不是正在工作。
- 群里做完一个项目后，助理会自动整理这个群较早的过程记录，后面的回复不再越来越慢。整理时会保留做过哪些项目、做成了什么、文件在哪、你的偏好和忌口，以及答应过还没做的事；只有记录确实很长时才整理，原始记录也都还在。使用高级记忆（Hindsight）时，项目交付那一刻，你在这个项目里说过的话会存进管理者的长期记忆。
- 每条消息的「引用」旁边多了「复制」，点一下就复制整条消息。
- 右键换成了程序自己的菜单，不再弹出浏览器的「后退、重新载入、检查元素」：
  - 在消息上右键可以复制、引用、另开新对话；先选中一段字再右键，只复制选中的部分。
  - 在其他地方选中文字后右键可以复制，在链接上右键可以复制链接。
  - 输入框里的右键照旧，方便粘贴。
- 手机通过局域网打开时，复制按钮（包括配对码、链接这些）也能正常用了。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

本轮除了用隔离的临时数据和模拟模型做自动测试，「项目交付后自动整理」还在单独的测试环境里，用真实模型和专门新建的测试助理、测试群实测过：连续做了几个项目，整理后再问「上次说以后再做的那件事」「上次那份表」「按上次的口味」，都答对了，忌口也没丢。工作状态显示和右键菜单只做了自动测试，还没在真实使用中看过。

# Pi Assistant v0.1.0-beta.67

这一版修了 Antigravity 在 Pi 里「聊一会儿就提示额度用完了」，可在 Antigravity 自己的 App 里一切正常的问题。

- **Antigravity 能一直聊下去了**：Google 会认出由 Pi 这类工具发出的请求，单独给一份很小的额度，用完就一律报「额度不足」。上一版去掉了一处会被认出的说明，但 Pi 的默认说明里还有一段介绍 Pi 自身文档的内容也会被认出，所以群聊里聊几十轮后又被拦住。现在交给 Antigravity 前把这段也去掉了。这段只讲 Pi 自己的用法，助理干活用不到，其他内容和其他模型渠道都不受影响。

这一版测试过的：
- 在和你的 App 分开的测试环境里，用同一个 Antigravity 账号新建测试助理，带着真实工具连续聊了 30 轮（共 130 次请求），一次都没有报额度不足；同一时间用旧的说明做对照，仍然会被拒。
- 用测试数据跑过单元测试和 Antigravity 的浏览器测试。
- 还没有在你装好的 App 和群聊里用新版本实际跑过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# Pi Assistant v0.1.0-beta.58

这一版把 Claude Code、Codex、Antigravity、OpenCode 也改成了和 Gemini CLI、CodeBuddy 一样的方式：Pi 自己装一份，和你电脑上的完全分开。

- **Pi 自己装一份**：这四个工具不再用你电脑上装的那份。在 设置 › 模型服务 › 编程工具 里点「安装」，Pi 会从官方地址下载固定版本，校验无误后装到 Pi 自己的目录里。
- **登录、设置、历史都分开**：
  - 它们用的是 Pi 单独的配置目录，不读你自己的设置、规则文件（比如 `CLAUDE.md`、全局 `AGENTS.md`）和登录。
  - 你电脑上的那份也完全不受影响。
- **登录方式**：点「登录」：
  - Claude Code、Codex 会打开浏览器，走官方登录。
  - OpenCode、Antigravity 会打开一个终端窗口，运行官方登录命令。
  - OpenCode 不登录也能用自带的免费模型。
- **不会自己更新**：这四个工具自带的自动更新都已关掉。你点「检查更新」才去查，点「更新」才会装。
- **干活方式不变**：选它们当模型时，动手照旧由 Pi 的工具来做，审批、记忆、助理电脑都和以前一样。

升级后需要注意：
- **要重新装一次、登录一次**：已经选了这些工具当模型的助理，模型选择不变，但要先在编程工具里点「安装」，再点「登录」，才能接着用。
- **旧对话会自动接上**：旧对话接不上原来的会话时，会自动把聊天记录交给新会话继续，不会卡住。
- **Mac 上第一次登录会弹系统提示**：第一次点 OpenCode 或 Antigravity 的「登录」，Mac 可能会问是否允许 Pi Assistant 控制终端，选允许就行。
- **Antigravity 要能连上 Google**：Antigravity 是从 Google 官方地址下载的。网络连不上 Google 的话，会装不上。

这一版测试过的：
- 用测试数据和假的安装包、假的登录程序，跑过全部单元测试。
- 6 个编程工具都跑过浏览器测试，走「没装 → 安装 → 登录 → 选为模型 → 对话」。
- 还没有真实下载安装、用真实账号登录过这些工具，也没有在 Windows、Linux 实机上试过登录。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# Pi Assistant v0.1.0-beta.36

- 群聊能自己往下推进了：
  - 去掉了每轮的 token 预算上限。以前成员干一次活就容易撞线，群里显示「本轮已暂停，回复继续」，要你开口才接着动；现在不会再因为这个停下。每轮发言次数的上限还在，用来防止来回空转。
  - 就算群因为发言次数暂停了，任务提交、卡住、定时检查照样会叫醒管理者，不用等你回复。
  - 开着自主推进时，管理者核验完、手上没活了，如果目标还没完成，会接着规划下一步、直接把任务派出去，不再只汇报一句就停；目标达成后它会明确结束自主推进，并告诉你结果。管理者一轮结束后手上没活，系统会再叫它一次；还是没有新安排，就只提醒你一次，不会一直空转。
- 「自主推进」开关挪到了群聊顶部，就在「任务」按钮旁边：没开时显示「自主推进」，点开写目标和完成标准就能开始；开着时显示「推进中」。你在群里交代一件需要多人、多步完成的事时，管理者也会主动发一张目标确认卡给你，点确认就开。**之前的群默认没开，想让它自己推进，记得点一下顶部的按钮。**
- 管理者派活时带的附件，现在会真的放进负责人的工作区，不会再出现「说派了、对方却拿不到文件」的情况；找不到的文件会直接说明，不再假装交接成功。
- 修复：文件卡片的长路径会超出卡片、压到下载按钮；「任务提交」卡片文字贴边，还和下面的系统提示叠在一起。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离的临时数据、Mock 模型和 Chromium 交互；真实模型下管理者会不会按目标持续推进，还需要你在实际使用中确认。

# v0.1.0-beta.73

- **聊天右栏更好找。** 常用入口和已打开的内容集中在同一个右栏。助理详情和完整模型设置复用现有控件；切换右栏内容不会清掉聊天草稿。窄屏仍可返回聊天。
- **图片和下载按钮对齐。** 聊天中的图片预览随可用宽度缩放，下载按钮贴着图片。预览和下载还是两个独立操作，下载保留原文件名和内容。
- **模型能力按渠道配置，不靠型号名猜。** 兼容的中转渠道可以声明一组模型共享的能力，并为个别模型设例外。换代后若协议和能力未变，可沿用渠道声明；图片无法按当前选择发送时会明确提示，不会静默丢掉图片继续发文字。已用本地模拟服务核对实际请求，尚未验证正式上游是否识图，也未确认真实渠道支持哪些思考档位。
- **测试启动与日常应用隔离。** 自动化测试明确使用临时数据和文件凭据后端。这不代表正式版聊天中出现的系统权限或迁移弹窗已经修好；该问题继续单独排查。

# Pi Assistant v0.1.0-beta.19

本次只提供 Apple 芯片 Mac 更新；Intel Mac、Windows 和 Linux 暂不发布此版本。

- 子代理默认每个助理同时运行 10 个，可在设置 › 模型中修改。满额时任务自动排队，空位释放后按顺序开始，不需要重新派活。
- 服务重启后，有会话记录的子代理会检查已完成进度并继续剩余任务；停止和取消的任务不会恢复。没有会话记录、无法确认进度的任务会说明原因，等待核验，不会从头重跑。
- 去掉聊天顶部和输入栏重复的电脑入口，电脑功能仍在右侧信息面板。输入栏根据实际可用宽度收起按钮文字，保留图标和悬停提示。
- 去掉输入栏底部过时的审批说明。beta.18 的完全权限应用层免审批行为保留。
- 单聊、群聊和子代理统一为 Shift+Enter 发送、Enter 换行，输入法选字时不会误发送。长任务标题和路径不再撑出子代理卡片。
- 图片点击后全屏预览，支持放大缩小、滚轮、拖动、双击、手机双指缩放、重置和下载；信息面板图片也使用同一个查看器。
- 修复自定义模型服务删除时的原生确认框不支持问题。删除前显示当前引用影响，失败会显示原因，删除后清理默认/识图/助理/子代理模型引用，保留历史用量。
- 修复桌面聊天外链被拦截的问题，外部网页交给系统默认浏览器打开。

已验证：前后端类型检查、网页构建、相关模型/权限/子代理单测、定向 Playwright、真实 Mock 服务进程重启续跑。macOS 安装冒烟通过后才公开更新。

已知限制：macOS 更新后系统权限可能要求重新授权。当前没有 Developer ID 签名证书，不能可靠保持 TCC 授权；这项尚未修复，不影响本次其他功能更新。重启时正在执行的外部操作可能状态不明，续跑会先核验，不能承诺任意操作恰好执行一次。

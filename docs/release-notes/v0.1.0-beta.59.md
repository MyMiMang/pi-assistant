# Pi Assistant v0.1.0-beta.59

这一版修的是：在 设置 › 模型服务 › 编程工具 里点「安装」装不上。

- **原因**：beta.58 里 Pi 调用 npm 下载工具时，把 npm 的两个配置文件指成了同一个，npm 直接拒绝运行。Claude Code、Codex、OpenCode 点安装一启动就失败。Mac 和 Windows 都是这样。
- **现在**：点「安装」会正常下载、校验、装好，装好后显示版本和「登录」按钮。
- **装不上时会显示原因**：以前失败了卡片上什么都不显示，看起来像没反应；现在会用红字写出「安装失败：原因」。
- 如果你在 beta.58 点安装时 Mac 弹出了一个显示 node 提示符的终端窗口，可以直接关掉，它没有在做任何事。

这一版测试过的：
- 在 Mac 的临时目录里，从官方 npm 真实安装了 Claude Code 2.1.322、Codex 0.167.0、OpenCode 1.19.5，都装成功，装的过程中没有弹出窗口。
- 新加了一个用真 npm 跑的测试，确认 npm 能正常读取配置；之前的测试用的是假 npm，所以没发现这个问题。全部单元测试和 5 个编程工具的浏览器测试都通过。
- 没有在 Windows 实机上点过安装；Antigravity 要从 Google 下载，这台电脑连不上，没有真实安装过；也还没有用真实账号登录过这些工具。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

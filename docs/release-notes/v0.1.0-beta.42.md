# Pi Assistant v0.1.0-beta.42

已于2026-10-27 03:20（北京时间）[公开发布为最新版](https://github.com/MyMiMang/pi-assistant/releases/tag/v0.1.0-beta.42)。五个平台构建、Mac/Windows安装启动检查均通过，自动更新清单和13项资产已核对；可在已安装App中检查更新。

这一版可以把电脑上已经登录好的编程命令行工具当成模型用：Claude Code、Codex，以及实验性的 Antigravity。它们只负责思考，读写文件、运行命令、操作电脑、记忆、审批这些仍然由 Pi 助理自己来做，权限和以前完全一样。

- 不用配置：电脑上装了、也登录了，模型列表里就会自动出现，例如「Claude Code · Sonnet」「Codex · GPT-6-Luna」「Antigravity · Claude Sonnet」。给助理选上就能用，单聊和群聊都可以。
- 模型服务页每家一张卡片，显示有没有安装、版本、有没有登录。后来才装好或刚登录的，点卡片上的「重新检测」就生效，不用重启。
- 用的是你自己的订阅，Pi 助理不另外计费，所以费用显示为 0；token 用量照常显示。
- 你在这些工具里自己配置的工具、插件、MCP、CLAUDE.md 不会被用上，所有操作都走 Pi 助理的审批和权限。
- 支持随时插话、停止，下一轮接着聊会记得前面的内容。

各家的情况：
- Claude Code：能显示思考过程，能识图。
- Codex：能显示思考摘要。如果你写过全局的 `~/.codex/AGENTS.md`，它也会一起发给 Codex，卡片上会提示。
- Antigravity（实验性）：第一轮回复要先启动，约 25 秒；不显示思考过程；暂不支持识图；插话会跟着下一个工具结果送到。它对网络要求高，需要地区受支持、出口 IP 固定的线路，否则会报「地区不支持」或连接被断开。

这一版在隔离的开发测试环境里，用真实的 Claude Code、Codex、Antigravity 实测过：单聊和群聊里调用工具读写文件、跨轮记得上下文、停止、停止后接着聊都正常。另外模拟了从程序坞启动 App 时很短的系统 PATH，三家都能找到并启动。没有实测的：Windows 和 Linux 上的使用，以及用订阅账号登录的 Claude Code（本机用的是中转）。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

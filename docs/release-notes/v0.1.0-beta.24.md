# v0.1.0-beta.24：统一模型服务、消息引用、记忆分层、AI 主题、语音输入与一批修复

> 状态：**beta.24 候选**（仅 Apple 芯片 Mac / arm64）。安装包由 CI 构建、Mac 安装冒烟通过后才公开；未签名构建每次更新后需要重新允许一次系统文件夹访问（已知，与本次无关）。

本次是一个较大的横跨版本：底层 Pi SDK 升到 1.2.0，模型/技能/记忆/外观/语音都有新能力，并修掉一批既有问题。

## 底层
- **Pi 官方 SDK 1.1.0 → 1.2.0**：只升官方发布包，**没有修改 Pi 本体、没有 fork、没有改 `node_modules`、没有用私有接口**；唯一的破坏性变动（回合事件按类型区分）在自有的 `pi-adapter` / 扩展里适配。每周自动升级流程也改了：只有测试通过才记录「已兼容的版本」。

## 模型服务（统一）
- **一个「模型服务」= 一份地址 + 一份密钥**，可同时提供对话 / 识图 / 生图 / 分类器；生图与快速操作模型不再单独填密钥。
- **去掉独立的「识图模型」选择器**：图片由**当前对话所用的模型**处理，不支持时明确告知，不会静默换成别的模型。
- **按需工具发现（tool_search / codemode）**：默认行为不变；启用后 MCP 工具按需出现，脚本里的调用同样要过审批，不会绕过权限。
- **本地 Laya（可选）**：一键下载安装后自动接入「快速操作模型」；不装也能用主模型操作电脑。
- **「实际操作测试」是真实受控桌面基准**（专用隔离窗口里真实观察→选择→点击），不是 API 延迟测试；**本机没有跑过真实基准，因此本次不给任何速度 / 性能提升承诺**。

## 技能
- 技能库统一（内置 / 用户 / 外部三类），**默认所有助理都不启用任何技能（内置也不启用）**，每个助理一份显式启用清单；主会话、子代理、后台任务共用同一份清单。
- 支持从**本地目录 / zip** 导入外部技能（同名不静默覆盖）；网络 git / URL 导入尚未支持。
- 发送前可以**点选本次要用的技能**（只列该助理已启用的；一次一个，只有单聊支持，群聊明确不支持）。

## 消息与群聊
- **引用回复**：单聊和群聊都能引用某条消息再回复（用户和助理的消息都可以被引用）；引用只是上下文，不是授权。
- 群聊「引用谁只叫谁」：@ 优先 > 被引用消息的作者 > 原有管理者；已删除 / 停用的成员不会误唤醒管理者；**只有你本人引用才会唤醒**。
- 重复点击或断线重发**不会重复入队**（同一条消息只处理一次）。
- **从某条「你发的」消息另开新对话**（单聊）：原对话完全不动，只复制前缀，那条消息正文回到输入框等你改完自己发（**不会自动重发、没有工具副作用**）；群聊与助理消息不支持这样分支。
- 整理上下文时可以写清「希望保留什么」（不写就是原来的行为）。

## 记忆
- **分层**：子代理 / 后台任务写的内容先作为任务草稿，不会直接进共享的用户记忆；主会话 / 你核验后可以晋升；只读自己作用域，越权不能靠换作用域绕过；已有的旧记忆照常可读。

## 外观（主题）
- 默认主题换成**暗夜**，删掉内置「极简」，新增一套**像素风**（浅 / 深都有）。
- **DIY + AI 造主题**：入口只在「设置 → 外观 → 用 AI 设计主题」（**没有**斜杠命令）；可以上传图片作**参考**（只作参考）；生成后先预览，确认保存才生效、取消完整恢复；保存后可继续用 AI 修改 / 另存为新主题 / 删除。
- 「把素材图当背景 / 装饰」本次**未实现，界面也不提供**（不承诺）。
- 首屏不再闪白：加载前就按上次的选择设好主题。

## 语音输入
- 输入栏的**语音转文字**（不是通话麦克风），按钮就在发送键左侧；只有你点按后才录音，录音结束立即停，结果只插入草稿，不自动发送。
- 云端语音识别在「设置 → 模型」里配置；**本地 SenseVoice**：许可适用范围尚未最终确认，因此**不随安装包分发、默认也不能下载**，只支持**导入你自行合法取得的权重**（导入时会按固定清单 + 校验和检查文件）。**本地语音本次没有在真机实测**。

## 手机与界面
- 修「手机每次打开都是第一个助理」和「切会话白屏、加载很久像坏了」：现在会恢复上次打开的助理 / 会话，并有加载骨架、失败重试、空态。
- 窄屏布局、安全区、发送 / 麦克风位置在手机上不再被挤出屏幕。
- 聊天附件可以**在应用内预览**：文本、Markdown（渲染 / 源码切换）、CSV、图片、PDF；为安全起见不执行 HTML / SVG / Office 文件。
- 子代理的思考强度可以按助理设默认、单个临时改、运行中改；各处下拉统一成应用内样式（不再用系统原生下拉）。

## 修复
- 聊天里的**外部链接**点了没反应（现在交给系统浏览器，失败会给可见提示）。
- 升级后被**强行重走首次设置向导**（现在只看持久配置，可恢复错误不再重置）。
- 设置 › 渠道里**删除按钮点不动**（改应用内确认框）。
- 单元测试污染真实数据目录，导致侧边栏**凭空多出助理**（测试数据目录强制隔离）。
- **发布前新发现并已修**：真实服务端的安全策略（CSP）原先会拦掉**语音采集的音频 worklet** 与 **PDF 预览**，也就是说安装版里这两个功能会静默失效；现在补上了必需的白名单并有浏览器级 e2e 覆盖。
- macOS 安装包补上**麦克风用途说明**（`NSMicrophoneUsageDescription`）：缺它时系统会在请求麦克风时直接终止进程。这是正常用途声明，不是绕过系统权限。

## 已知问题 / 未验证（如实）
- **未验证**：真实云模型的生成质量与参考图效果、真实云端语音识别、真实设备（真机安装包 / 手机 / iOS）、真实 MCP（cua-driver / http 服务）端到端、本地 SenseVoice 的实际安装与转写、真实电脑操控基准。本地验证用的是 Mock 模型 + 真实 Pi 会话 / 真实 HTTP / 真实浏览器（链路上是真的，模型和硬件是假的）。
- 系统钥匙串弹窗的**根因仍未查明**；本次没有重置钥匙串、没有清空用户数据。测试用的助理「小微」与那条测试渠道行仍未删除（等你确认）。
- 未做 Apple 代码签名 / 公证：每次更新后 macOS 会再问一次系统文件夹权限（历史问题，与本次改动无关）。
- 微信等渠道的真实重连、助理电脑（虚拟机）开机、快速操作模型的真实性能，都要在安装版里再验证。

本次仅提供 Apple 芯片 Mac（arm64）安装与自动更新包；Intel Mac、Windows、Linux 本轮不构建。

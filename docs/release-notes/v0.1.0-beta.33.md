# Pi Assistant v0.1.0-beta.33

- 助理设置改成固定的八个分类：概览、模型、资料、能力、任务、记忆、文件、电脑。概览一眼看到大脑、操作你的电脑、任务三行摘要；模型页直接用输入框下那个模型按钮，模型、思考、Fast 一套操作，各自即时保存；资料页显式保存，没改动时不再提示「已保存」，套用人设模板只换人设。
- 输入框下去掉权限档位和主动程度按钮，改到助理设置的「电脑」和「任务」页调整；模型按钮在地方够时把思考、Fast 和模型目录直接铺开，窄窗口自动收成两层。
- 任务页：定时任务和主动跟进共用一份免打扰设置，子页改为「定时任务 / 执行记录 / 主动跟进」。
- 文件页和电脑页：工作文件夹移到「文件」并默认折叠；电脑页助理电脑在前，长列表折叠显示数量。
- 中转服务：接口格式支持「自动」，按模型名识别协议；新建时按地址预填名称和格式；服务详情改成单列，模型列表可搜索、可一键测试全部。
- 高级记忆：新增健康角标和通知、备用记忆模型、三步自检（每步显示真实耗时，服务没运行时如实说明跳过）；记忆页「待核验」改叫「待确认」，选项收进「高级」。
- 设置里技能库、模型服务、桌宠、操作这台电脑、助理电脑等长列表统一默认折叠、限高滚动，说明收进「?」。
- 群聊：输入框草稿切群不丢；管理者收尾不再占成员发言上限；助理改名改头像后群里即时刷新。
- 修复：在已有对话里刚添加邮箱等新能力后，助理调用时报「找不到工具」，现在续接对话也能马上用上。
- 修复：首次运行向导选好默认模型后没有「下一步」按钮。
- 修复：语音设置里本地模型下拉每次跳回推荐项，现在停在你保存的模型。
- Pi 和高级记忆（Hindsight）的版本随安装包固定，App 不会自己检查或升级它们；App 自身的自动更新照旧。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五平台构建，以及 Mac、Windows 安装启动检查通过后才公开自动更新。

本轮验证为隔离 Mock 服务和 Chromium 交互（完整 e2e 63 步、服务端 957 项单测通过）；不代表已完成所有系统与物理手机的验收。语音挪成可选模块本版没有做。

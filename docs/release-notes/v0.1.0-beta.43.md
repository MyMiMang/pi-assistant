# Pi Assistant v0.1.0-beta.43

发布中：tag 已推送，等五个平台构建和安装检查通过后公开。

这一版接着上一版的「本机编程命令行当模型」做两处改进：Claude Code 能选的模型和 Claude Code 里完全一样了；App 启动也不会再被这几个命令行工具拖慢。

- Claude Code 的模型列表不再只有 Opus / Sonnet / Haiku 三个，而是向你电脑上的 Claude Code 问出来的完整清单，和你在 Claude Code 里用 /model 能选的一样，比如「默认」、带 1M 上下文的型号等。每个模型能选的思考强度也跟 Claude Code 一致。
  - 如果你在 Claude Code 里通过中转把模型换成了别的（比如 CC Switch），名字后面会带上实际的模型名，例如「Claude Code · Opus（claude-opus-5-5）」，方便分清。
  - 后来在 Claude Code 里改了配置，点模型服务页 Claude Code 卡片上的「重新检测」，列表就会更新。
  - 问不到列表时（比如还没登录），会退回 Opus / Sonnet / Haiku 三个，已经选了这几个的助理照常能用。
- App 启动更快：以前启动时要依次检查 Claude Code、Codex、Antigravity，其中 Antigravity 要联网，界面得等它们都检查完才打开。现在界面先打开，这几家在后台同时检查，好了以后模型列表会自动出现，不用刷新。
  - 刚启动的那几秒里给用这几家模型的助理发消息，会等它准备好再回答，不会悄悄换成别的模型。

这一版在隔离的开发测试环境里实测过：重启后界面立刻能用，Claude Code 和 Codex 的模型约 3 秒出现，Antigravity 约 16 秒出现；Claude Code 列出了 6 个模型，选带 1M 上下文的那个让助理建文件、读文件，正常完成。没有实测的：Windows 和 Linux 上的使用，以及用订阅账号登录的 Claude Code（本机用的是中转）。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# Pi Assistant v0.1.0-beta.61

这一版整理了 设置 › 模型服务 里模型渠道列表的布局。

- **模型渠道也收起来了**：OpenAI、Anthropic、DeepSeek 和自己加的中转站这些渠道，现在收在一个「模型渠道」分组里，跟「编程工具」一样默认折叠。标题旁显示一共几个、已经配好几个。点开后能搜索，列表长了就在框里滚动。
- **「添加服务」随时能点**：按钮在「模型渠道」这一行右边，列表收起时也能直接点。加完后列表会自动展开，能马上看到新加的渠道。
- **搜索框不再压字**：模型服务里的搜索框，放大镜图标以前会压在提示文字上，现在不会了。

这一版测试过的：
- 用测试数据跑过单元测试，以及模型服务页、设置易用性和 4 个编程工具卡片的浏览器测试，电脑和手机宽度都看过截图。
- 没有在你装好的 App 里测试过。

提供 Mac Apple 芯片、Intel Mac、Windows x64、Linux x64/arm64 安装包。发布流程要求五个平台都构建成功，并且 Mac、Windows 的安装启动检查通过后，才开放自动更新。

# 写周报

1. 素材来源（按顺序）：用户这次给的内容 → 工作区里相关文件 → memory_recall 搜索本周的日志（kind=log）。
2. 结构：
   - **本周完成**（3–6 条，动词开头，尽量量化结果）
   - **进行中 / 风险**（写清卡点与需要的支持）
   - **下周计划**（3–5 条）
3. 语气客观、简洁，不写空话；每条一行。
4. 输出成 `reports/周报-YYYY-MM-DD.md` 并 deliver_file 发给用户，同时在聊天里贴出正文。
5. 用户说明了固定的格式偏好时，用 memory_save（kind=fact, scope=user）记下来，下次直接沿用。
